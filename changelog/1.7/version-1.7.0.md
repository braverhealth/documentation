# Version 1.7.0

#### 1. Nouvelles fonctionnalités

1. Amélioration du flou d'arrière-plan lors des appels vidéo pour une meilleure qualité et stabilité
2. Validation des fichiers avant envoi pour éviter les messages de fichiers invalides

#### 2. Améliorations

1. Meilleurs cadrages vidéo lors des appels avec des proportions optimisées (environ 4:3) pour éviter de couper les visages

#### 3. Corrections

1. Correction du problème d'expansion du partage d'écran lors des appels
2. Correction du problème de session verrouillée sur certaines versions
3. Correction des données incohérentes dans la vue des patients
4. Correction de la barre de recherche verrouillée lorsque le panneau de prévisualisation est ouvert
5. Correction de la vidéo inversée sur la version web
6. Correction de l'affichage des segments supprimés dans l'application
7. Correction du problème de synchronisation entre l'application mobile et la version web
