# Version 1.7.0

#### 1. Nouvelles fonctionnalités

1. Amélioration du flou d'arrière-plan lors des appels vidéo pour une meilleure qualité visuelle
2. Validation des fichiers avant l'envoi pour éviter les erreurs de téléversement

#### 2. Améliorations

1. Amélioration des cadrages vidéo lors des appels pour mieux afficher les visages des participants

#### 3. Corrections

1. Correction du problème d'expansion du partage d'écran lors des appels
2. Correction d'un problème de cohérence des données dans l'affichage des informations patients
3. Correction de la barre de recherche qui restait verrouillée lorsque le panneau d'aperçu était ouvert
4. Correction de la vidéo inversée sur la version web
5. Correction de l'affichage des segments supprimés qui restaient visibles dans l'application
6. Correction du problème de synchronisation entre l'application mobile et la version web
