# Version 1.6.14

#### 1. Corrections

1. Correction du problème où l'équipe du créateur n'était pas toujours incluse lors de la création d'un fil à l'intérieur d'un canal de soins
2. Correction du problème où la session utilisateur ne pouvait pas être déverrouillée avec le code PIN sur le web
3. Correction du problème où le résumé du canal de soins ne se rafraîchissait pas de manière fiable
4. Correction du problème où les messages sans contenu faisaient apparaître les discussions comme non lues
5. Correction du problème où la flèche de synchronisation restait affichée dans certaines conditions de connectivité
6. Correction du problème où l'auteur de l'extrait de discussion n'était pas correct
