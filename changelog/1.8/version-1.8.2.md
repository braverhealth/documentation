# Version 1.8.2

#### 1. Nouvelles fonctionnalités

1. **Voir les contacts invités dans les équipes d'un milieu de travail** — Il est maintenant possible de voir les contacts invités directement dans la liste des équipes d'un milieu de travail.
2. **Indicateur de notifications désactivées dans les paramètres de profil** — Lorsqu'un utilisateur a refusé les permissions de notification, un indicateur rouge apparaît sur l'avatar de profil dans la barre de navigation, puis sur l'icône d'engrenage. Une bannière dans les paramètres de profil invite l'utilisateur à activer les notifications ou à être notifié par courriel.
