# Version 1.11.1

#### 1. Nouvelles fonctionnalités

1. Vous pouvez rejoindre un appel Braver Connect dans le navigateur de votre téléphone sans installer l'application

#### 2. Améliorations

1. Dans l'application clinicienne, consultez et retouchez vos photos et vidéos pendant leur téléversement
2. Les transferts de fichiers sont plus fluides
3. Le titre par défaut est désormais facultatif dans les modèles de discussion
4. Les formulaires indiquent les formats acceptés et les limites de taille avant l'ajout d'une pièce jointe
5. Le retour d'un sous-formulaire conserve votre position
6. Sur Android, les formulaires PDF sont plus faciles à remplir avec le clavier et le sélecteur de dates

#### 3. Corrections

1. Le filtre par trajectoire tient compte de vos droits d'accès aux canaux de soins
2. Le rôle de gestion s'applique dès la création d'un canal de soins
3. Le numéro d'assurance maladie et les longs identifiants s'affichent correctement dans les dossiers patients
4. Les choix de réponse des formulaires s'affichent au complet
5. Les champs permettant de joindre plusieurs fichiers s'affichent correctement
6. Les formulaires PDF envoyés incluent la dernière réponse saisie
7. Après avoir partagé un formulaire dans une nouvelle discussion, vous restez sur la page où vous vous trouviez
