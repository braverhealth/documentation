# Activate Account via Integrated Bubble

## Step-by-Step

{% hint style="info" %}
PILOTS: Have you tested the app in the pre-production environment? You will need to repeat this process once you move to production.
{% endhint %}

{% stepper %}
{% step %}
**When opening the integrated bubble in software like Gustav or Leomed, you will see the following options:**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-15 at 13.45.38@2x.png" alt="" width="354"><figcaption></figcaption></figure></div>

**If you have never used Braver independently or in a third-party software, choose the option&#x20;**_**I do not have a Braver account yet**_**.**
{% endstep %}

{% step %}
**You will be asked to confirm that you really want to continue without associating an existing Braver account, as the action will not be reversible. Select OK.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-15 at 13.45.46@2x.png" alt="" width="350"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**You will then need to set up a 6 digits passcode.**

{% hint style="info" %}
This passcode will be useful, among other things, if you want to use Braver on a mobile device.
{% endhint %}

**Click on&#x20;**_**Set passcode**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/set_passscode.png" alt="" width="375"><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
**Enter your PIN, then enter it again to confirm.**

<div align="left"><figure><img src="../../.gitbook/assets/PIN_EN.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Finally, you will need to accept Braver's terms of use.**

**Scroll to the bottom, then click on&#x20;**_**Accept terms of service**_**&#x20;if you want to continue.**

<div align="left"><figure><img src="../../.gitbook/assets/terms_of_service.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**You're all set! Your Braver account is now activated.**

<div align="left"><figure><img src="../../.gitbook/assets/Youre_in_Braver.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
