# Invite a Healthcare Professional to Join Braver Network

## Step by Step

{% stepper %}
{% step %}
**Go to the Network page.**

<div align="left"><figure><img src="../../.gitbook/assets/access_network.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Search for the name of the person you want to join.**

<div align="left"><figure><img src="../../.gitbook/assets/search_network.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**They are not part of the network? Click on&#x20;**_**Invite a New Member**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.12.18@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Fill in all invitation fields. Make sure to choose the correct profession for your invitee. When you invite a member to the network, you vouch for their identity.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.12.50@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Add his workplace**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.15.17@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Activate the toggle&#x20;**_**Send invitation now**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.15.51@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Choose your invitee’s language preference.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.19.43@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Select your preferred option between&#x20;**_**Send by email**_**&#x20;or&#x20;**_**Share a link**_**&#x20;(see step 9).** &#x20;

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.20.14@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>

{% hint style="info" %}
**It is possible to add a security question that only the recipient knows the answer to. Like with a bank transfer, we want to ensure the right person accepts the invitation.**&#x20;

![](<../../.gitbook/assets/CleanShot 2026-04-16 at 08.20.38@2x.png>)
{% endhint %}
{% endstep %}

{% step %}
**Enable Send by link if you want to send your invitation by SMS, for example.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.20.56@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Click on&#x20;**_**Send invitation**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.21.08@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
