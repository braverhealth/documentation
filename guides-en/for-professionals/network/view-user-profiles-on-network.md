# View User Profiles on the Network

## Step-by-Step

{% stepper %}
{% step %}
**Go to the Network page.**

<div align="left"><figure><img src="../../.gitbook/assets/access_network.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Select the person whose profile you want to view.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-15 at 15.42.07@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**If the person does not appear in your contacts, use the search icon and type their name to find them.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-15 at 15.42.18@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Once you find the person, click their name to open their profile.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-15 at 15.42.35@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**In their profile, select Detailed profile.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-15 at 15.43.21@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Depending on what the person has set up, you will be able to view their bio, their profession (if they are on Braver’s external network), and their workplace.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-15 at 15.43.29@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
