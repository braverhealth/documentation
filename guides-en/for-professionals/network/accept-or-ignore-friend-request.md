# Accept or Ignore a Friend Request

## Step by Step

{% hint style="warning" %}
Currently, once the friend request is accepted, it is impossible to close the direct messaging channel.

This is a limitation that will be corrected soon.
{% endhint %}

{% stepper %}
{% step %}
**Go to the Network page.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 09.18.56@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**To accept a friend request, go to Network tab and select this friendship icon in top right.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 09.19.05@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Select the received invitation.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 09.19.14@2x.png" alt="" width="362"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**At this point, you can&#x20;**_**Accept**_**&#x20;or&#x20;**_**Ignore**_**&#x20;the friend request. If you prefer to ignore the request, the person who invited you will not receive a message about it.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 08.56.44@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
