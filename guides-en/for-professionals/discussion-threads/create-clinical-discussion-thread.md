## Scenario 1: Add one or more participants

{% stepper %}
{% step %}
**Go to the&#x20;**_**Home**_**&#x20;page.**

<div align="left"><figure><img src="../../.gitbook/assets/Access_home_page (1).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Select the bubble icon at the bottom of the page.**

<div align="left"><figure><img src="../../.gitbook/assets/create discussion thread.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Choose Clinical Thread.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.26.19@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Select Choose a Patient.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.23.22@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Use the search bar to find the relevant patient. 2) Click the desired patient.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.29.23@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Check the record to make sure it is the correct patient. Then click&#x20;**_**Create in this patient**_**.**&#x20;

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.23.43@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Select an existing care channel or choose&#x20;**_**Outside of any channel**_**. In this example,&#x20;**_**Outside of any channel**_**&#x20;is selected.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.23.55@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**In the composition menu:**

1. **Enter a title for your message.**
2. **Write the message content.**
3. **Select&#x20;**_**Attachments**_**&#x20;to add files if needed.**
4. **Set the priority to urgent if needed.**
5. **Click&#x20;**_**Next**_**&#x20;to go to the second composition page.**

{% hint style="info" %}
At this stage, if you selected a care channel in step 7, you will not be able to edit the participants, since they are predefined by the care channel. You will be able to do it once your message has been sent.

See the tutorial [_Manage Discussion Thread Participants_](https://support-en.braver.net/guides/for-healthcare-professionals/discussion-threads/manage-discussion-thread-participants) for more details.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.25.00@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Click&#x20;**_**Add a participant**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.25.27@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
1. &#x20;**Use the search bar to find the participants you want.**&#x20;
2. **Click the name of the person you want to add.**

{% hint style="info" %}
To add a team, see [_Scenario 2: Add one or more teams_](create-clinical-discussion-thread.md#scenario-2-add-one-or-more-teams) below.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/search_participant.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**After selecting the participant, click&#x20;**_**Add to the discussion**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/add_team_to_the discussion.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Click&#x20;**_**Send**_**&#x20;at the bottom of the page.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-20 at 13.40.11@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**Where to find them:**

* Clinical threads are available from the _Home_ page. They are the ones linked to a patient record and shown in purple.
* You can also find clinical threads from the _Patients_ page by selecting the relevant patient.
* You can also find clinical threads from the _Network_ page by selecting one of your collaborators in the thread.
{% endhint %}
