# Filter Patient Files

{% hint style="info" %}
Filters let you [filter patient record](filter-patient-files.md#id-1.-filter-patient-records)s and [view the status of their invitation process](filter-patient-files.md#id-2.-view-the-invitation-process-status).
{% endhint %}

## 1. Filter patient records

### Step-by-step

{% stepper %}
{% step %}
**Go to the Patients page, then select Filters.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 14.56.43@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Choose one or more of those options.**

{% hint style="info" %}
Filters vary depending on the roles assigned to you and the configurations set by your establishment.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 14.57.42@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Click Save.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-16 at 14.58.24@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

### Use Cases

1. **To quickly identify patients where you are part of an active discussion, select those options:**

2. **If you are covering for a teammate and want to see ongoing active discussions, select this option:**
