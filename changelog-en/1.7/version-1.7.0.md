# Version 1.7.0

#### 1. New Features

1. Banner indicating when other participants are not allowed to respond
2. Banner indicating when nobody is currently available in the discussion
3. Support for downloading files in embedded iframes
4. Improved background options during video calls

#### 2. Improvements

1. Improved video framing during calls

#### 3. Fixes

1. Fixed teams not displayed in organization units with parent
2. Fixed bug on create message button and improved UX
3. Fixed PIN code during SSO onboarding not working with keyboard
4. Fixed frontend validation to prevent broken optimistic file messages
5. Fixed segment deletion not visible in app
6. Fixed synchronization issue between mobile app and web version
7. Fixed screenshare expansion displaying person instead of screen
8. Fixed inconsistent data with JoinedPatientView
9. Fixed search bar locked when peek panel is open
10. Fixed inverted video on web
