# Version 1.7.0

#### 1. New Features

1. Warning banner when other participants are not allowed to respond in a discussion
2. Warning banner when nobody is currently available in a discussion
3. File downloads even when the app is embedded in an iframe
4. Improved video background options during calls (reduced flickering)

#### 2. Improvements

1. Improved video framing during calls to avoid cutting off participants' faces

#### 3. Fixes

1. Fixed teams not displayed in organization units with parent
2. Fixed create message button and improved user experience
3. Fixed PIN code configuration during SSO onboarding with keyboard
4. Fixed frontend validation to prevent optimistic file messages that would fail
5. Fixed deleted segments not appearing in the app
6. Fixed synchronization issues between mobile app and web version
7. Fixed screen share expansion during calls (expanding person instead of screen share)
8. Fixed search bar locked when details panel is open
9. Fixed inverted video on web during calls
