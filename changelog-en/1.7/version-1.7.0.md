# Version 1.7.0

#### 1. New Features

1. Informative banner when other participants are not allowed to respond in a discussion
2. Informative banner when nobody is currently available in a discussion
3. Support for downloading files even when in an embedded iframe
4. Improved display of background options during video calls

#### 2. Improvements

1. Improved video framing during calls to better display participants' faces

#### 3. Fixes

1. Fixed teams not displayed in organization units with parent
2. Fixed bug on create message button and improved user experience
3. Fixed PIN code input with keyboard during SSO onboarding
4. Fixed frontend validation to prevent broken optimistic file messages
5. Fixed segment deletions not appearing in the app
6. Fixed synchronization issues between mobile app and web version
7. Fixed screen share expansion during calls
8. Fixed inconsistent data when creating multiple patient view instances
9. Fixed search bar locked when peek panel is open
10. Fixed inverted video on web
