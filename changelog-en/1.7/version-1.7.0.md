# Version 1.7.0

#### 1. New Features

1. Informative banner when other participants are not allowed to respond in a discussion
2. Informative banner when nobody is currently available in a discussion
3. Support for downloading files even when embedded in an iframe
4. Improved background options during video calls (blur and images)

#### 2. Improvements

1. Improved video framing during calls to avoid cutting off participants' faces

#### 3. Fixes

1. Fixed teams not displayed in organization units with parent
2. Fixed bug on create message button and improved user experience
3. Fixed PIN code entry with keyboard during SSO onboarding
4. Fixed frontend validation to prevent optimistic file messages that would fail
5. Fixed deleted segments not appearing in the app
6. Fixed synchronization issue between mobile app and web version
7. Fixed screenshare expansion during calls
8. Fixed issue with multiple instances of JoinedPatientView giving inconsistent data
9. Fixed search bar locked when peek panel is open
10. Fixed inverted video on web
