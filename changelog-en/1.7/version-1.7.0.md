# Version 1.7.0

#### 1. New Features

1. Improved background blur during video calls for better quality and stability
2. File validation before sending to prevent invalid file messages

#### 2. Improvements

1. Better video framing during calls with optimized aspect ratios (approximately 4:3) to avoid cutting off faces

#### 3. Fixes

1. Fixed screen share expansion issue during calls
2. Fixed locked session issue on certain versions
3. Fixed inconsistent data in patient view
4. Fixed search bar locked when peek panel is open
5. Fixed inverted video on web version
6. Fixed deleted segments not appearing correctly in the app
7. Fixed synchronization issue between mobile app and web version
