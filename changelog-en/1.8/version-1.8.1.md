# Version 1.8.1

#### 1. New Features

1. **Team member assignment mode configuration in care threads** — It is now possible to configure how team members are assigned by default when creating a new thread in a care channel. Three modes are available: a single designated person (Single), no members included by default (None), or all team members participating in the channel (All).
