# Version 1.8.2

#### 1. New Features

1. **View invited contacts in workplace teams** — It is now possible to see invited contacts directly in the team list of a workplace.
2. **Notification disabled indicator in profile settings** — When a user has declined notification permissions, a red indicator appears on the profile avatar in the navigation bar, then on the gear icon. A banner in the profile settings prompts the user to enable notifications or opt for email notifications instead.
