# Version 1.6.12

#### 1. New Features

1. Background noise removal during calls (web only)
2. Camera button redesign
3. Picture in Picture mode for calls (web only)

#### 2. Improvements

1. Show drafts in patients/care channels/contacts pages
2. Improved video tiles layout on mobile calls
3. Option to uncheck all participants when calling
4. Display archived care channels

#### 3. Fixes

1. Fixed patient onboarding QR code scanning issues
2. Fixed missing action menu in pending file drawer
3. Fixed patients page hidden for unvalidated standalone users
4. Fixed auto-filled secret code invitations reappearing after acceptance
5. Fixed invitation re-acceptance issues
6. Fixed user not prompted to join channel in thread creation
7. Fixed infinite loading for removed caregivers
8. Fixed inability to save active caregiver details
9. Fixed SMS invitation language issues
