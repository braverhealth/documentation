# Créer un nouveau canal de soins

## Pas-à-pas

{% stepper %}
{% step %}
**1) Accédez à la page&#x20;**_**Patients**_**&#x20;et 2) sélectionnez le patient qui vous intéresse ou 3) retrouvez-le grâce à la barre de recherche.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.38.10@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur 1) les trois points et 2) sur&#x20;**_**Créer un canal**_**&#x20;dans le menu.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.40.39@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Donnez un titre au nouveau canal et 2) indiquez quels participants vous souhaitez impliquer dans le canal de soins en cliquant sur&#x20;**_**Inviter**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.14.07@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**À ce moment, vous pourriez choisir un participant 1) en utilisant la barre de recherche ou 2) à partir d'un&#x20;**_**lieu de travail**_**&#x20;ou 3) en cliquant sur vos contacts.**

Pour l'exemple suivant, j'ai sélectionné un lieu de travail.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.17.16@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Si vous désirez impliquer une équipe au&#x20;**_**canal de soins**_**, 1) cliquez directement sur&#x20;**_**Ajouter à la discussion**_**&#x20;dans le haut du&#x20;**_**lieu de travail**_**, puis 2) sélectionnez ensuite la ou les équipes nécessaires en répétant les dernières étapes.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.23.31@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**S'il s'agit d'un canal de soins vous permettant de communiquer avec les patients et/ou les proches aidants, activez-les en cliquant sur&#x20;**_**Ajouter**_**&#x20;vis-à-vis la ligne qui les représente.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.09.55@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Une fois vos participants sélectionnés, cliquez sur&#x20;**_**Suivant**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.24.41@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Inscrivez votre premier message et 2) ajoutez du contenu si vous le désirez. Pour terminer, 3) créez le canal en cliquant sur&#x20;**_**Créer**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.27.03@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Votre nouveau canal de soins a été créé dans la fiche patient sélectionnée.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-01-21 at 14.36.08@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
