### Ajouter un lieu de travail à mon profil

{% hint style="info" %}
Il est possible d'avoir plus d'un lieu de travail!
{% endhint %}

{% stepper %}
{% step %}
**1) Accédez à votre profil via votre avatar en bas de l'écran, puis 2) cliquez sur votre nom.**

<div align="left"><figure><img src="../../.gitbook/assets/accéder paramètres 2.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Défilez au bas de la page et cliquez sur&#x20;**_**Rejoindre un lieu de travail**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.18.15@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Utilisez la barre de recherche pour trouver votre lieu de travail.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.19.45@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Votre lieu de travail existe déjà dans Braver? Sélectionnez-le comme dans l'exemple. Sinon, consultez la section** [_**Créer un nouveau lieu de travail dans le réseau Braver**_](ajouter-un-lieu-de-travail-a-mon-profil.md#creer-un-nouveau-lieu-de-travail-dans-le-reseau-braver) **pour poursuivre.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.20.38@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez ensuite sur&#x20;**_**Rejoindre**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.21.30@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Déclarez que vous travaillez dans cet établissement, 2) indiquez la date de début et cliquez sur&#x20;**_**Rejoindre ce lieu de travail.**_

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.22.18@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Vous apparaissez maintenant dans la liste des professionnels qui travaillent dans ce lieu.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.42.30@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Votre nouveau lieu de travail apparaît dans votre profil également.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.24.23@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>

### Créer un nouveau lieu de travail dans le réseau Braver

{% stepper %}
{% step %}
**Si le lieu de travail n'a pas encore été créé dans Braver, cliquez sur&#x20;**_**Créer un nouveau lieu de travail**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-15 at 15.22.09@2x.png" alt="" width="251"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Inscrivez le lieu de travail que vous souhaitez créer dans la boîte de recherche au haut de la page. Un ou plusieurs choix provenant de Google Maps apparaîtront dans le menu, sous la barre de recherche. 2) Sélectionnez celui qui vous convient.**

{% hint style="info" %}
Il est également possible d'entrer une adresse manuellement. Voir encadré vert sur l'image ci-dessous.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 15.25.36@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Vous pouvez 1) ajouter une unité si désiré, puis 2) cliquez sur suivant.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-15 at 15.34.34@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
**Sélectionnez une catégorie provenant du menu déroulant.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-15 at 20.06.03@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur&#x20;**_**Suivant**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-15 at 15.28.30@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Déclarez que vous travaillez dans cet établissement, 2) indiquez la date de début et 3) cliquez sur&#x20;**_**Suivant.**_

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 15.26.44@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Vous apparaissez maintenant dans la liste des professionnels qui travaillent dans ce lieu.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-05-27 at 14.42.30@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
