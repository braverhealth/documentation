# Copier un message à partir d'un fil de discussion

{% stepper %}
{% step %}
Dans le fil de discussion qui vous intéresse, survolez le message que vous souhaitez copier avec votre curseur. Vous pourrez alors cliquer sur les 3 petits points qui apparaîtront.

{% hint style="info" %}
Si vous êtes sur mobile, maintenant le message enfoncé pour faire apparaître le menu d'action.&#x20;
{% endhint %}
