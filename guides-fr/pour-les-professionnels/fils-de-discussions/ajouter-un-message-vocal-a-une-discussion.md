# Ajouter un message vocal à une discussion

## Pas-à-pas

{% hint style="info" %}
Cette fonctionnalité est disponible seulement sur mobile.
{% endhint %}

{% stepper %}
{% step %}
**Accédez à la page&#x20;**_**Accueil.**_

<div align="left"><figure><img src="../../.gitbook/assets/1-Accueil.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionnez le fil de discussion dans lequel vous désirez transmettre un message vocal.**

<div align="left"><figure><img src="../../.gitbook/assets/fil actif.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur l'icône du micro pour débuter l'enregistrement.**

<div align="left"><figure><img src="../../.gitbook/assets/IMG_3476.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Lorsque vous êtes prêt, cliquez sur l'icône du micro.&#x20;**_**Vous n'avez pas à le maintenir appuyé**_**.**

{% hint style="info" %}
Avant d'initier l'enregistrement, vous pouvez également choisir la langue de votre choix (anglais ou français).
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-07 at 12.56.20@2x.png" alt="" width="347"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Enregistrez votre message, puis cliquez sur le bouton orange d'arrêt.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-07 at 12.57.49@2x.png" alt="" width="350"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Vous pouvez maintenant modifier le texte à votre guise.**

1. Si vous désirez reprendre votre enregistrement, sélectionnez la flèche qui fait un retour en arrière (à gauche).
2. Pour vous écouter, appuyez sur l'icône « Jouer » (au centre).
3. Pour l'envoyer, cliquez sur l'avion en papier (à droite).

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-07 at 12.58.40@2x.png" alt="" width="253"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Votre interlocuteur pourra alors vous écouter ou lire votre retranscription.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-07 at 13.00.20@2x.png" alt="" width="340"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
