# Créer un nouveau fil de discussion clinique

## Pas-à-pas

{% stepper %}
{% step %}
**Accédez à la page&#x20;**_**Accueil**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/1-Accueil.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionnez la bulle dans le bas de la page.**

<div align="left"><figure><img src="../../.gitbook/assets/Créer un nouveau fil de discussion clinique - Step 1.jpeg" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Choisissez le&#x20;**_**Fil clinique**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 13.37.00@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionnez « Choisir un patient ».**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 13.37.43@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Utilisez la barre de recherche afin de retrouver le patient concerné. 2) Cliquez sur le patient désiré.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 13.43.13@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Vérifiez le contenu de la fiche pour s'assurer qu'il s'agit du bon patient. Cliquez sur « créer dans ce patient ».**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 13.38.10@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionnez un canal de soins existants ou choisissez « hors de tout canal ». Dans cet exemple, « hors de tout canal » est sélectionné.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 13.38.44@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Dans le menu de rédaction :**

1. **Indiquez un titre pour votre message.**
2. **Rédigez le contenu du message.**
3. **Cliquez sur « pièces jointes » pour ajouter des fichiers si nécessaire.**
4. **Définissez la priorité comme urgente si besoin.**
5. **Cliquez sur « suivant » pour accéder à la deuxième page de rédaction.**

{% hint style="info" %}
À ce stade, si vous avez sélectionné un canal de soins dans l'étape 5, vous ne pourrez pas modifier les participants, puisqu'ils sont prédéterminés par le canal de soins. Vous pourrez le faire une fois votre message envoyé.

Consultez le tutoriel _Gérer les participants d'un fil de discussion_ pour plus de détails à cet effet.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 13.55.32@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur « ajouter un participant ».**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 14.00.00@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
1. **Utilisez la barre de recherche pour trouver les participants souhaités.**
2. **Cliquez sur le nom de la personne que vous désirez ajouter.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 13.09.59@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Après avoir sélectionné le participant, cliquez sur « Ajouter à la discussion ».**

<div align="left"><figure><img src="../../.gitbook/assets/Ajouter un participant.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur « envoyer » en bas de la page.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-09 at 19.45.10@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

{% hint style="success" %}
**Où les retrouver :**

* Les _fils cliniques_ sont accessibles à partir de l'onglet _Accueil_. Ce sont ceux qui sont reliés à une fiche patient en violet.
* Vous pouvez également retrouver les _fils cliniques_ sous l'onglet _Patients_, en sélectionnant le patient concerné.
* Vous pouvez également retrouver les _fils cliniques_ sous l'onglet _Réseau_, en sélectionnant l'un de vos collaborateurs à ce fil.
{% endhint %}

## Autre chemin pour créer un fil de discussion clinique

Dans l'onglet _Patients_ > Choisissez un patient > Cliquez sur l'icône de bulle de discussion
