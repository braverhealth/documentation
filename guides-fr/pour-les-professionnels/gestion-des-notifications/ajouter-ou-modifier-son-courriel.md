# Ajouter ou modifier son courriel

{% hint style="info" %}
Braver vous envoie des notifications de nouveaux messages et des récapitulatifs hebdomadaires par courriels. Si vous vous connectez via l'un de nos partenaires d'intégration, il est possible que votre courriel ne soit pas partagé à Braver; vous pouvez l'ajouter manuellement.&#x20;
{% endhint %}

{% stepper %}
{% step %}
### Cliquez sur votre avatar de profil.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.20.24@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Cliquez sur votre nom.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.21.17@2x.png" alt="" width="372"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélectionnez l'onglet _Paramètres_.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.21.57@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sous le titre Communications, cliquez sur _Courriel(s)_.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.22.34@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Cliquez sur _Ajouter_.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 15.58.47@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>

{% hint style="info" %}
Si vous souhaitez remplacer un courriel existant par un nouveau, la page ressemblera plutôt à ceci:

<img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.36.23@2x.png" alt="" data-size="original">
{% endhint %}
{% endstep %}

{% step %}
### Inscrivez votre courriel, puis cliquez sur _Ajouter ce courriel_.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.27.38@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Un code de validation sera envoyé à votre courriel. Ouvrez votre boîte de réception et recherchez un courriel intitulé _Braver | Code de sécurité pour nouvelle adresse courriel_.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.29.34@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Copiez le code de sécurité contenu dans le courriel.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.31.15@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Retournez à la page d'ajout de courriel et collez le code dans le champ prévu.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.30.38@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Cliquez sur _Valider_ pour finaliser l'ajout du courriel.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.33.04@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Cliquez sur _Désigner comme principal_.

{% hint style="info" %}
Désignez-le comme principal si vous souhaitez modifier un ancien courriel par celui-ci ou s'il s'agit de votre premier courriel ajouté à vos paramètres!
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.33.48@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Votre courriel apparaît maintenant avec la mention _Principal_.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.34.52@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
