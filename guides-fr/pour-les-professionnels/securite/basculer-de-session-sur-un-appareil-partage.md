# Verrouiller votre session ou vous déconnecter

## Pas-à-pas

### Verrouiller votre session

{% stepper %}
{% step %}
**1) Accédez à votre profil via votre avatar en bas de l'écran, puis 2) cliquez sur&#x20;**_**Changer de session**_**.**

{% hint style="info" %}
Le bouton pourrait se nommer _Verrouiller la session_ s'il n'y a aucune autre session d'active sur votre appareil.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-04 at 19.50.11@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Il sera alors possible de choisir une session active comme dans l'exemple ou d'en ajouter une nouvelle. Vous pouvez accéder rapidement à votre session verrouillée grâce à votre NIP.**

<div align="left"><figure><img src="../../.gitbook/assets/basculer-de-session-sur-un-appareil-partage - Step 3.jpeg" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

### Vous déconnecter

{% stepper %}
{% step %}
**1) Accédez à votre profil via votre avatar en bas de l'écran, puis 2) cliquez sur&#x20;**_**Me déconnecter.**_

{% hint style="info" %}
La prochaine fois que vous désirerez vous connecter sur cet appareil, vous devrez fournir votre courriel, votre mot de passe et confirmer votre identité avec un code de sécurité reçu par courriel ou SMS.
{% endhint %}

{% endstep %}
{% endstepper %}
