# Accepter une invitation

## Pas-à-pas

{% stepper %}
{% step %}
**Dans le courriel que vous avez reçu, 1) copiez le code secret et 2) cliquez sur le bouton vous invitant à accepter l'invitation.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.15.48 AM@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Collez le code secret dans le champ demandé, puis cliquez sur&#x20;**_**Valider le code secret**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.17.25 AM@2x (1).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Est-ce la première fois que vous ouvrez Braver?** Choisissez l'option _Créer un nouveau compte_.

<div align="left"><figure><img src="../../.gitbook/assets/créer nouveau compte.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Inscrivez le mot de passe de votre choix. 2) Sélectionnez ensuite&#x20;**_**Créer mon compte**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.52.22 AM@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Faites défiler jusqu'en bas de la page et acceptez les conditions d'utilisation.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.52.44 AM@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Configurez un NIP pour déverrouiller facilement votre application si la reconnaissance faciale n'est pas disponible. Cliquez sur&#x20;**_**Configurer**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.52.54 AM@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Entrez votre NIP et répétez-le une seconde fois.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.53.06 AM@2x.png" alt="" width="371"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionnez&#x20;**_**Ces réglages me conviennent**_**&#x20;ou modifiez-les, au besoin.** Si vous changez d'avis, vous pourrez toujours les modifier dans vos paramètres, sous _Modifier mes paramètres de joignabilité_.

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.53.15 AM@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Choisissez si vous consentez aux communications ou non.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-09-18 at 10.53.26 AM@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Votre compte est créé! 🎉
{% endstep %}
{% endstepper %}

## Autres cas

### Cas 1:

Si c'est la première fois que vous ouvrez Braver, mais que Braver a déjà été utilisé par quelqu'un d'autre sur votre appareil, vous verrez un écran comme le suivant :

<div align="left"><figure><img src="../../.gitbook/assets/creation-de-compte-via-une-invitation - Option 1.png" alt="" width="375"><figcaption></figcaption></figure></div>

Vous pouvez alors choisir l'option _Créer un nouveau compte_ pour poursuivre la création de votre compte. Si vous avez déjà créé un compte Braver auparavant, cliquez sur votre nom ou sur _Utiliser un compte Braver existant_, puis saisissez vos informations de connexion.

### Cas 2

Si vous avez déjà créé votre compte auparavant avec la même adresse courriel que celle de l'invitation, mais que votre session n'est pas active sur votre appareil, vous verrez un écran comme le suivant :

<div align="left"><figure><img src="../../.gitbook/assets/creation-de-compte-via-une-invitation - Option 3.png" alt="" width="375"><figcaption></figcaption></figure></div>

Dans ce cas, entrez votre mot de passe pour vous connecter.

### Cas 3

Si vous avez déjà créé votre compte auparavant avec la même adresse courriel que celle de l'invitation et que votre session est active sur votre appareil, vous verrez un écran comme le suivant :

<div align="left"><figure><img src="../../.gitbook/assets/creation-de-compte-via-une-invitation - Option 4.png" alt="" width="375"><figcaption></figcaption></figure></div>

Dans ce cas, entrez simplement votre NIP pour vous connecter.
