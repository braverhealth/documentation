# Création de compte autonome

## Pas-à-pas

{% hint style="warning" %}
Suite à votre création de compte, vous recevrez un code de récupération qui vous sera utile si vous perdez votre mot de passe. Gardez ce code dans un endroit sécuritaire!
{% endhint %}

{% stepper %}
{% step %}
**À l'ouverture de l'application, cliquez sur :&#x20;**_**Inscrivez-vous gratuitement !**_

<div align="left"><figure><img src="../../.gitbook/assets/creation-de-compte-autonome - Step 1.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Inscrivez votre adresse courriel et le mot de passe de votre choix. Sélectionnez ensuite&#x20;**_**Créer mon compte**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-08-12 at 15.41.34@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Récupérez le code de sécurité à 6 chiffres dans vos courriels et saisissez-le dans le champ de texte prévu à cet effet.**

{% hint style="info" %}
N'oubliez pas de vérifier vos indésirables s'il n'apparaît pas dans votre boîte courriel rapidement.
{% endhint %}

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-08-12 at 15.38.24@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
**Créez votre profil. Cliquez sur&#x20;**_**Créer un profil**_**&#x20;pour enregistrer vos informations.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-08-12 at 15.42.29@2x.png" alt="" width="291"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Faites défiler jusqu'en bas de la page et acceptez les conditions d'utilisation.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-08-12 at 15.40.16@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Configurez un NIP qui vous servira à déverrouiller facilement votre application si vous n'avez pas l'option de reconnaissance faciale. Cliquez sur&#x20;**_**Configurer**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-08-12 at 15.43.49@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Entrez votre NIP et répétez-le une seconde fois.**

<div align="left"><figure><img src="../../.gitbook/assets/creation-de-compte-autonome - Step 11.jpeg" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Acceptez ou refusez le&#x20;**_**Consentement aux communications**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-08-12 at 15.46.12@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Il ne vous reste plus qu'à faire valider votre profession par Braver pour avoir accès aux diverses fonctionnalités. Prenez connaissance de ce message et cliquez sur&#x20;**_**J'ai compris**_**!**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-08-12 at 15.49.26@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
