# Écrire à une équipe

{% hint style="info" %}
Mettre un message ici pour référer aux boîtes de triage.
{% endhint %}

## Pas-à-pas

{% stepper %}
{% step %}
**Accédez à la page&#x20;**_**Accueil**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/1-Accueil.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Débutez un nouveau fil de discussion en cliquant sur la bulle:**&#x20;

* [**Pour débuter un fil clinique, suivez ce guide.**](https://support.braver.net/guides/pour-les-professionnels/fils-de-discussions/creer-un-fil-de-discussion-clinique)&#x20;
* [**Pour débuter un fil non clinique, suivez plutôt ce guide.**](https://support.braver.net/guides/pour-les-professionnels/fils-de-discussions/creer-un-fil-de-discussion-non-clinique)

<div align="left"><figure><img src="../../.gitbook/assets/Écrire à une équipe - Step 1.jpeg" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Vous voici dans le menu de rédaction d'un message. 1) Indiquez un titre, 2) ajoutez un message et 3) cliquez sur&#x20;**_**Suivant**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/rédaction fil (fenêtre 1).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur&#x20;**_**Ajouter un participant**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/ajouter participant (fenêtre 2).png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Pour inviter une équipe, cliquez sur le lieu de travail de l'équipe en question. Si vous ne voyez pas le lieu de travail désiré, utilisez la barre de recherche dans le haut de la page.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-04 at 14.57.18@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sous le nom du lieu de travail, cliquez sur 1)&#x20;**_**Ajouter à la discussion,**_**&#x20;puis 2) sélectionnez l'équipe désirée.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-04 at 14.49.50@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../../.gitbook/assets/%C3%89crire%20%C3%A0%20une%20%C3%A9quipe%20-%20Step%208.jpeg" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**On voit ici que l'équipe Infirmières a bien été sélectionnée. Terminez la rédaction de votre message et cliquez sur&#x20;**_**Envoyer**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-02-04 at 14.55.43@2x.png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
