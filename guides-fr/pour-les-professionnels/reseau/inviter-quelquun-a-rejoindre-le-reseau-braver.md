# Inviter quelqu'un à rejoindre le réseau Braver

## Comprendre le réseau Braver

Le réseau Braver se compose de deux parties distinctes :
- **Le réseau interne** : Les professionnels de la santé déjà validés et actifs sur la plateforme
- **Le réseau externe** : Les professionnels qui peuvent être invités à rejoindre la plateforme

Il existe trois façons pour un professionnel de la santé de rejoindre le réseau Braver.

## Méthodes pour rejoindre le réseau Braver

### 1. Auto-inscription
Un professionnel peut télécharger l'application Braver et soumettre les documents requis :
- Pièce d'identité
- Preuve d'exercice professionnel

### 2. Invitation par un professionnel validé
Un professionnel de la santé déjà membre du réseau peut inviter un collègue à rejoindre la plateforme.

### 3. Entrée institutionnelle
Une institution de santé peut décider d'intégrer ses professionnels au réseau simultanément.

## Pas-à-pas pour inviter un collègue

{% stepper %}
{% step %}
#### Identifiez un collègue avec qui vous collaborez fréquemment (par exemple, un pharmacien) et naviguez vers l'onglet Réseau dans l'application.

{% hint style="info" %}
**À noter :** Vous pouvez inviter n'importe quel professionnel de la santé avec qui vous travaillez régulièrement.
{% endhint %}

#### Remplissez les informations requises : prénom, nom de famille et profession.

{% hint style="warning" %}
**Important :** Assurez-vous de l'exactitude des informations, car en invitant cette personne, vous endossez son identité professionnelle.
{% endhint %}

<!-- Image à ajouter : Screenshot du formulaire d'invitation -->
<div align="left"><figure><img src="../../.gitbook/assets/inviter-quelquun-a-rejoindre-le-reseau-braver - Step 3.jpeg" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
#### Ajoutez une question de sécurité pour vérifier l'identité de la personne invitée.

Cette mesure de sécurité fonctionne comme un virement bancaire : elle garantit que le message atteint la bonne personne. Choisissez une question dont seul le destinataire connaît la réponse.

{% hint style="info" %}
**Exemple de questions de sécurité :**
- Dans quelle clinique travaillons-nous ensemble ?
- Quel est le nom de notre patient commun [initiales] ?
- Lors de quelle conférence nous sommes-nous rencontrés ?
{% endhint %}

{% step %}
#### Choisissez comment envoyer l'invitation :

**Option 1 : Par courriel**
Si vous avez l'adresse courriel de la personne, sélectionnez « Inviter par courriel ».

**Option 2 : Par lien d'invitation**
Vous pouvez partager un lien d'invitation via SMS ou d'autres plateformes de messagerie.

## Après l'envoi de l'invitation

Une fois l'invitation envoyée, la personne invitée recevra :
- Un lien pour télécharger l'application Braver (si elle ne l'a pas déjà)
- Les instructions pour créer son compte
- La question de sécurité à laquelle elle devra répondre pour confirmer son identité

{% hint style="success" %}
**Astuce :** Prévenez votre collègue que vous lui avez envoyé une invitation pour faciliter le processus d'inscription.
{% endhint %}
