# Activer un compte patient ou proche aidant sur un appareil géré par l'établissement (Leomed)

{% hint style="danger" %}
Cas d'usage: Seulement pour les patients ou proches aidants **à qui vous prêtez un appareil géré par l'établissement**.
{% endhint %}

## Pas-à-pas

{% stepper %}
{% step %}
**Dans une fiche patient de Leomed, cliquez sur l'icône de Braver en haut de la fiche du patient à gauche.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2025-01-09 at 22.43.36@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Ouvrez la caméra de l'appareil mobile iOS ou Android prêté par l'établissement et scannez le code QR.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-14 at 10.45.24@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionnez&#x20;**_**Je n'ai pas encore de compte Braver**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-14 at 08.43.14@2x.png" alt="" width="284"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur&#x20;**_**OK**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-14 at 08.44.20@2x.png" alt="" width="285"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Faites défiler les conditions générales d'utilisation de Braver jusqu'en bas, puis 2) cliquez sur&#x20;**_**Accepter les conditions d'utilisation**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/braver_condi_screenshot.png" alt="" width="283"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**1) Faites défiler les conditions générales d'utilisation de Leomed jusqu'en bas, puis 2) cliquez sur&#x20;**_**Accepter les conditions d'utilisation**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/leomed_condi_screenshot.png" alt="" width="283"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur&#x20;**_**Confirmer cette permission**_**&#x20;au sujet des notifications push.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-14 at 08.51.13@2x.png" alt="" width="245"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur&#x20;**_**Autoriser**_**&#x20;pour confirmer.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-14 at 08.57.56@2x.png" alt="" width="191"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Refaites les étapes 7 et 8 pour la caméra et le micro.**
{% endstep %}

{% step %}
**Voilà! Vous avez bien créé le compte du patient ou du proche aidant!**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-14 at 10.43.50@2x.png" alt="" width="284"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
