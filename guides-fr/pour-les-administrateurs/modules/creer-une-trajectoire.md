# Créer une trajectoire

{% hint style="info" %}
Une trajectoire est un modèle de canal de soins. Lorsque vous configurez une trajectoire, vous pouvez ensuite rapidement créer des canaux de soins pour plusieurs patients, selon le même modèle. Le titre du canal de soins sera déjà défini, de même que les acteurs que vous souhaitez voir participer au canal de soins. \
\
C'est également à cet endroit que vous pouvez prévoir un modèle de fil de discussion, ce qui peut vous être utile si vous avez à recopier fréquemment un même message dans le contexte de votre canal de soins.\
\
Plusieurs configurations sont possibles; n'hésitez pas à demander conseil à la personne qui vous accompagne dans votre déploiement!
{% endhint %}

#### 2.1 Modifier les informations d'un acteur

{% stepper %}
{% step %}
**1) Sélectionnez l'onglet&#x20;**_**Informations**_**. Voici les options qui s'offrent à vous:**

A. Modifier le nom de l'acteur;

B. Ajouter une description de l'acteur. Cette description apparaîtra sous le nom de l'acteur dans le menu de gauche;

C. Forcer la sélection de cet acteur en activant l'interrupteur. À ce moment, l'acteur devra obligatoirement faire partie de la trajectoire;

D. Indiquer un nombre maximal de ce type d'acteur dans la trajectoire. Laissez à 0 pour un nombre illimité;

E. Décider si le mode d'assignation est:

* Unique: Toujours inclure un membre de l'équipe s'il est assigné au canal ou s'il est le seul membre de l'équipe participant au canal;
* Tous: Tous les membres de l'équipe participant au canal seront inclus dans les fils de discussion;
* Aucun: Aucun membre de l’équipe qui participe au canal ne sera inclus dans les fils de discussion; ceux-ci arriveront dans la boîte de triage de l’équipe.

### 4. Modifier la suggestion automatique

{% hint style="info" %}
C'est ici que vous pouvez configurer quand une trajectoire sera automatiquement suggérée dans les fiches patients. Vous pouvez restreindre les suggestions selon le statut du patient et définir une plage de dates. \
\
Vous pouvez ainsi sauver des clics lors de l'activation en plus de rendre vos équipes autonomes si elles ont la responsabilité de configurer un canal de soins pour les patients.

<img src="../../.gitbook/assets/CleanShot 2026-07-14 at 15.01.31.png" alt="" data-size="original">
{% endhint %}

{% stepper %}
{% step %}
**Sélectionnez 1)&#x20;**_**Modules**_**, puis 2) l'onglet&#x20;**_**Trajectoires**_**. Choisissez ensuite 3) la trajectoire désirée.**

<figure><img src="../../.gitbook/assets/CleanShot 2026-07-14 at 13.54.07.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
**1) Sélectionnez l'onglet&#x20;**_**Suggestion automatique**_**. Voici les options qui s'offrent à vous:**

{% hint style="info" %}
Il est possible d'activer plus d'une option.
{% endhint %}

A) _Quand le patient est actif:_ Cette trajectoire sera suggérée pour tous les patients actifs;

B) _Quand absent du patient:_ Cette trajectoire sera suggérée automatiquement, en excluant ceux dont le canal de soins correspondant existe déjà;

C) _Avant la date:_ Indiquez jusqu'à quand vous souhaitez que la suggestion automatique soit suggérée dans la fiche du patient;

D) _À partir de la date:_ Indiquez à partir de quand la trajectoire doit être suggérée dans la fiche du patient.

{% endstep %}
{% endstepper %}
