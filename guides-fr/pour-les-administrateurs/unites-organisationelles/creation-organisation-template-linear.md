# Guide pour la création d'organisations gérées par Joël

Ce guide explique comment utiliser le template Linear pour créer une nouvelle organisation dans le système.

## 1. Introduction au template

Un template a été créé pour structurer les demandes de création d'organisations gérées par Joël. Cela facilite le processus de création et assure que toutes les informations nécessaires sont collectées.

![Introduction au template](../../.gitbook/assets/creation-organisation-template-01.png)

## 2. Accéder à la création d'une nouvelle organisation

Pour commencer le processus :

1. Cliquez sur le bouton « **Nouveaux discussions** »
2. Cela génère un nouveau « Issue » dans Linear

![Accéder à la création](../../.gitbook/assets/creation-organisation-template-02.png)

## 3. Sélectionner le template approprié

Une fois dans le nouvel issue :

1. Cliquez sur « **Template** »
2. Choisissez « **Création d'une organisation** »

![Sélectionner le template](../../.gitbook/assets/creation-organisation-template-03.png)

## 4. Remplir les informations de l'organisation

Complétez les informations suivantes :

- **Nom de l'organisation** (en anglais ou en français)
- **Descriptions détaillées**, incluant :
  - Nom complet
  - Adresse complète

![Remplir les informations](../../.gitbook/assets/creation-organisation-template-04.png)

## 5. Ajouter des équipes et des admins

### Équipes
Mentionnez les équipes (en anglais ou en français) et leur association au Workplace.

### Administrateurs (optionnel)
Désignez les admins à inviter dès le départ, en incluant :
- Nom
- Profession
- Courriel
- Besoin potentiel de :
  - Trajectoire
  - Identifiant personnalisé
  - Botin

![Ajouter équipes et admins](../../.gitbook/assets/creation-organisation-template-05.png)

## 6. Soumettre la demande

Une fois toutes les informations complétées :

- La création de l'issue sera automatiquement assignée à **Joëlle**
- Cela apparaîtra dans sa liste de tâches, facilitant le suivi et la coordination

![Soumettre la demande](../../.gitbook/assets/creation-organisation-template-06.png)

## 7. Suivi et coordination

Après la soumission :

- Joëlle pourra suivre l'avancement de la requête
- Elle pourra poser des questions additionnelles si nécessaire via les commentaires de l'issue

![Suivi et coordination](../../.gitbook/assets/creation-organisation-template-07.png)
