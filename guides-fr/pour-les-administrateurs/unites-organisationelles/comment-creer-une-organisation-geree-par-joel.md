# Comment créer une organisation gérée par Joël ?

{% embed url="https://www.loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3" fullWidth="true" %}

## Pas-à-pas

{% stepper %}
{% step %}
#### Comprendre le template de création

Un template a été créé pour structurer les demandes de création d'organisations gérées par Joël. Cela facilite le processus de création et assure que toutes les informations nécessaires sont collectées.

{% endstep %}

{% step %}
#### Accéder à la création d'une nouvelle organisation

Cliquez sur le bouton « Nouveaux discussions ». Cela génère un nouveau « Issue » dans Linear.

{% endstep %}

{% step %}
#### Sélectionner le template approprié

1. Cliquez sur « Template »
2. Choisissez « Création d'une organisation »

{% endstep %}

{% step %}
#### Remplir les informations de l'organisation

Indiquez les informations suivantes :

* **Nom de l'organisation** (en anglais ou en français)
* **Adresse complète** de l'organisation

Assurez-vous de fournir des descriptions détaillées pour faciliter le traitement de la demande.

{% endstep %}

{% step %}
#### Ajouter des équipes et des admins

* Mentionnez les **équipes** (en anglais ou en français) et leur association au Workplace
* **Optionnel** : Désignez les admins à inviter dès le départ, en incluant :
  * Nom
  * Profession
  * Courriel
  * Besoin potentiel de trajectoire, d'identifiant personnalisé et de botin

{% endstep %}

{% step %}
#### Soumettre la demande

Une fois tous les champs remplis, soumettez la demande. La création de l'issue sera assignée à Joëlle, ce qui facilitera le suivi et la coordination.

{% endstep %}

{% step %}
#### Suivi et coordination

Joëlle pourra :

* Suivre l'avancement de la requête
* Poser des questions additionnelles si nécessaire
* Coordonner la création de l'organisation

{% endstep %}
{% endstepper %}

## Points à retenir

> ⚠️ **Important** : Assurez-vous de fournir toutes les informations requises dans le template pour éviter des délais de traitement. Plus les détails sont complets, plus rapide sera la création de votre organisation.
