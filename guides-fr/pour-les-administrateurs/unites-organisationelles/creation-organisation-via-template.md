# Création d'une organisation via le template Linear

Ce guide vous explique comment utiliser le template Linear pour créer une demande de création d'organisation gérée par Joël.

## 1. Introduction au template
*[Timestamp: 0:03](https://loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3?t=3)*

- Un template a été créé pour structurer les demandes de création d'organisations gérées par Joël.
- Cela facilite le processus de création.

## 2. Accéder à la création d'une nouvelle organisation
*[Timestamp: 0:11](https://loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3?t=11)*

- Cliquez sur le bouton « Nouveaux discussions ».
- Cela génère un nouveau « Issue » dans le Linear.

## 3. Sélectionner le template approprié
*[Timestamp: 0:19](https://loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3?t=19)*

- Cliquez sur « Template ».
- Choisissez « Création d'une organisation ».

## 4. Remplir les informations de l'organisation
*[Timestamp: 0:24](https://loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3?t=24)*

- Indiquez le nom de l'organisation (en anglais ou en français).
- Ajoutez des descriptions détaillées, y compris :
  - Nom
  - Adresse complète

## 5. Ajouter des équipes et des admins
*[Timestamp: 0:32](https://loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3?t=32)*

- Mentionnez les équipes (en anglais ou en français) et leur association au Workplace.
- Optionnel : désignez les admins à inviter dès le départ, en incluant :
  - Nom
  - Profession
  - Courriel
  - Besoin potentiel de trajectoire, d'identifiant personnalisé et de botin

## 6. Soumettre la demande
*[Timestamp: 0:59](https://loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3?t=59)*

- La création de l'issue sera assignée à Joëlle.
- Cela apparaîtra dans sa liste de tâches, facilitant le suivi et la coordination.

## 7. Suivi et coordination
*[Timestamp: 1:12](https://loom.com/share/5c45cf5e43e54a08a2886d1e5cae2bc3?t=72)*

- Joëlle pourra suivre l'avancement de la requête.
- Elle pourra poser des questions additionnelles si nécessaire.
