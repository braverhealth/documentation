# Comment créer une organisation

## Introduction au template

Un template a été créé pour structurer les demandes de création d'organisations gérées par Joël. Cela facilite le processus de création et assure que toutes les informations nécessaires sont collectées.

## Étapes de création

### 1. Accéder à la création d'une nouvelle organisation

- Cliquez sur le bouton « Nouveaux discussions ».
- Cela génère un nouveau « Issue » dans Linear.

### 2. Sélectionner le template approprié

- Cliquez sur « Template ».
- Choisissez « Création d'une organisation ».

### 3. Remplir les informations de l'organisation

Indiquez les informations de base de l'organisation :

- **Nom** : Le nom de l'organisation (en anglais ou en français)
- **Adresse complète** : L'adresse physique complète de l'organisation

{% hint style="info" %}
Assurez-vous que le nom de l'organisation est clair et que l'adresse est complète pour éviter les délais de traitement.
{% endhint %}

### 4. Ajouter des équipes et des admins

Mentionnez les équipes et leur association au Workplace :

- **Équipes** : Listez les équipes (en anglais ou en français) et leur lien avec le Workplace

**Optionnel** : Désignez les admins à inviter dès le départ, en incluant :

- Nom
- Profession
- Courriel
- Besoin potentiel de trajectoire, d'identifiant personnalisé et de botin

{% hint style="warning" %}
Si vous prévoyez d'ajouter des admins lors de la création, assurez-vous d'avoir toutes leurs informations de contact correctes pour éviter les erreurs d'invitation.
{% endhint %}

### 5. Soumettre la demande

Une fois que vous avez rempli tous les champs requis :

- La création de l'issue sera assignée à Joëlle
- Cela apparaîtra dans sa liste de tâches, facilitant le suivi et la coordination

### 6. Suivi et coordination

Après la soumission :

- Joëlle pourra suivre l'avancement de la requête
- Elle pourra poser des questions additionnelles si nécessaire
- Vous recevrez des mises à jour sur l'état de votre demande

{% hint style="tip" %}
Consultez régulièrement l'issue créée pour suivre la progression de votre demande de création d'organisation.
{% endhint %}
