# Ajouter un fichier, une photo ou une vidéo à un fil de discussion

## Pas-à-pas

* #### **Sur ordinateur**
  * [Ajouter une pièce jointe](ajouter-un-fichier-une-photo-ou-une-video-a-un-fil-de-discussion-patient.md#sur-ordinateur)
* #### **Sur mobile**
  * [Ajouter une pièce jointe ](ajouter-un-fichier-une-photo-ou-une-video-a-un-fil-de-discussion-patient.md#ajouter-une-piece-jointe-sur-mobile)
  * [Prendre une photo ou une vidéo](ajouter-un-fichier-une-photo-ou-une-video-a-un-fil-de-discussion-patient.md#prendre-une-photo-ou-une-video-sur-mobile)

### Sur ordinateur

{% stepper %}
{% step %}
**Dans le fil de discussion avec votre équipe de soins, faites un choix parmi les suivants:**

* **Cliquez sur le symbole « + » pour ajouter une photo, une vidéo ou un fichier.**&#x20;
* **Cliquez sur l'icône du trombone pour ajouter un fichier. Passez à l'étape 3.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 13.23.06@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Si vous cliquez sur le « +», faites un choix parmi les suivants:**

* **Cliquez sur&#x20;**_**Joindre une photo ou une vidéo**_**&#x20;pour partager une photo ou une vidéo avec votre équipe de soins.**
* **Cliquez sur&#x20;**_**Joindre un fichier**_**&#x20;pour partager une image ou toute autre documentation sous format PDF, DOC ou MP3 avec votre équipe de soins.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 13.14.44@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionner, dans les dossiers de votre ordinateur, l'élément que vous souhaitez partager et cliquez sur&#x20;**_**Ouvrir**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 13.15.40@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**À ce moment, vous pouvez encore retirer l'élément à envoyer:**

1. **Cliquez sur les trois petits points à la droite de l'élément.**
2. **Cliquez sur sur&#x20;**_**Retirer le fichier**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 13.54.19@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Pour terminer, appuyez sur la flèche violette pour que votre pièce jointe soit bien envoyée.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 13.17.20@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Votre pièce jointe a bien été transmise!**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 13.17.40@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

### Ajouter une pièce jointe sur mobile

{% stepper %}
{% step %}
**Dans le fil de discussion avec votre équipe de soins:**

* **Cliquez sur le symbole « + » pour ajouter une photo, une vidéo ou un fichier.**&#x20;
* **Cliquez sur l'icône du trombone pour ajouter un fichier.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 14.14.28@2x.png" alt="" width="323"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Si vous cliquez sur le « +», faites un choix parmi les suivants:**

1. **Cliquez sur&#x20;**_**Joindre une photo ou une vidéo**_**&#x20;pour partager une photo ou une vidéo avec votre équipe de soins.**
2. **Cliquez sur&#x20;**_**Joindre un fichier**_**&#x20;pour partager une image ou toute autre documentation sous format PDF, DOC ou MP3 avec votre équipe de soins. Passez à l'étape 4.**

<div align="left"><figure><img src="../../.gitbook/assets/choix du + (mobile) ajout photo.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Si vous cliquez sur&#x20;**_**Joindre un photo ou une vidéo**_**, faites un choix parmi les suivants:**

1. **Cliquez sur&#x20;**_**Photothèque**_**&#x20;pour partager une photo ou une vidéo apparaissant sur la pellicule de votre appareil avec votre équipe de soins.**
2. **Cliquez sur Prendre photo ou vidéo pour prendre la photo sur-le-champ. Passez à la section** [_**Prendre un photo ou vidéo sur mobile**_](ajouter-un-fichier-une-photo-ou-une-video-a-un-fil-de-discussion-patient.md#prendre-une-photo-ou-une-video-sur-mobile)**.**
3. **Cliquez sur&#x20;**_**Choisir le fichier**_**&#x20;pour partager une image ou toute autre documentation sous format PDF, DOC ou MP3 avec votre équipe de soins.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 14.10.34@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Sélectionner l'élément que vous souhaitez partager et cliquez sur&#x20;**_**Ouvrir.**_

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 15.07.13@2x.png" alt="" width="342"><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
**À ce moment, vous pouvez encore retirer l'élément à envoyer:**

1. **Cliquez sur les trois petits points à la droite de l'élément.**
2. **Cliquez sur sur&#x20;**_**Retirer le fichier**_**.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 14.11.40@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
**Pour terminer, appuyez sur la flèche violette pour que votre pièce jointe soit bien envoyée.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 14.11.22@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Votre pièce jointe a bien été transmise!**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 15.25.56@2x.png" alt="" width="323"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

### Prendre une photo ou une vidéo sur mobile

{% hint style="info" %}
Une photo ou vidéo prise via Braver n'apparaîtra pas sur la pellicule de votre appareil.
{% endhint %}

{% stepper %}
{% step %}
**Dans le fil de discussion avec votre équipe de soins cliquez sur le symbole « + ».**&#x20;

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 14.14.28@2x.png" alt="" width="323"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur&#x20;**_**Joindre une photo ou une vidéo**_**&#x20;pour partager une photo ou une vidéo avec votre équipe de soins.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 15.33.58@2x.png" alt="" width="282"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Cliquez sur&#x20;**_**Prendre photo ou vidéo.**_

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 15.33.34@2x.png" alt="" width="284"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Votre caméra ouvrira, prenez votre photo ou votre vidéo.**

<div align="left"><figure><img src="../../.gitbook/assets/CleanShot 2026-04-01 at 14.10.48@2x.png" alt="" width="375"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
**Si votre photo vous satisfait, cliquez sur&#x20;**_**Utiliser la photo**_**. Sinon, cliquez sur&#x20;**_**Reprendre**_**&#x20;pour revenir à l'étape 4.**

**Pour terminer, appuyez sur la flèche violette pour que votre photo ou vidéo soit bien envoyée.**
