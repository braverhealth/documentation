#### Terminer la communication avec le patient

{% hint style="info" %}
Si un fil de discussion est ouvert dans le canal de soins incluant le patient, celui-ci peut vour répondre. Si vous choisissez de fermer le fil de discussion, à ce moment, le patient ne peut plus vous écrire. Il aura toujours accès à la discussion et aux pièces jointes, mais ne pourra pas les modifier.
{% endhint %}
