# Vendored theme

Started from [starlight-theme-nova](https://github.com/ocavue/starlight-theme-nova) 0.12.3 (MIT, see `LICENSE`).
It is now owned and maintained here; there is no upstream sync.

Braver changes:
- Registered by `src/theme/index.ts` instead of the npm plugin.
- Twoslash removed.
- `PageFrame` and `MobileMenuToggle` follow Starlight 0.42's mobile-menu contract.
