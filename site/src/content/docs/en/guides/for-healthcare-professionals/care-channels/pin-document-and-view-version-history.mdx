## Step-by-Step

<Steps>
<ol>

<li>

#### To pin a file (photos, videos, documents) in a care channel, access a discussion thread in the care channel containing the file you want to pin.

<Figure src={img0} alt="Care channel with a closed discussion thread highlighted" width={650} align="left" />

</li>

<li>

#### Click on the 3 small dots (web) or long press on the file (mobile).

<Figure src={img1} alt="Discussion thread video attachment with its more options button highlighted" width={650} align="left" />

</li>

<li>

#### Click on _Pin Document_.

<Figure src={img2} alt="Video attachment menu with Pin document highlighted" width={650} align="left" />

A small red pin will appear next to the file.

</li>

<li>

#### If we return to view the care channel details, we can see our pinned file.

We can replace this version of the document with a newer version. To do this, click on the 3 small dots (web) or long press on the file (mobile).

<Figure src={img3} alt="Pinned video in Recent content with its more options button highlighted" width={650} align="left" />

</li>

<li>

#### Click on the option to update.

<Figure src={img4} alt="Pinned attachment menu with Update from existing file highlighted" width={650} align="left" />

</li>

<li>

#### This will create a new thread to notify participants that a new version is uploaded. Write a message explaining the changes and complete the send.

<Figure src={img5} alt="New thread form with a message and updated video attachment" width={650} align="left" />

</li>

<li>

#### In the care channel, we now see the latest version of the file.

To view previous versions of the documents, click on the 3 small dots (web) or long press on the file (mobile).

<Figure src={img6} alt="Updated pinned video with its more options button highlighted" width={650} align="left" />

</li>

<li>

#### Click on _Open File History_.

<Figure src={img7} alt="Video attachment menu with Open file history highlighted" width={650} align="left" />

</li>

<li>

#### You will then see all versions of the file in question.

<Figure src={img8} alt="File history showing two video versions and their authors" width={650} align="left" />

</li>

</ol>
</Steps>
