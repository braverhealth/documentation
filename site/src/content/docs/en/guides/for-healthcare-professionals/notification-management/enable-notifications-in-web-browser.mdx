If you previously blocked Braver notifications in your browser, you need to open the site settings to turn this permission back on.

1. [Google Chrome](/en/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#google-chrome)
2. [Microsoft Edge](/en/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#microsoft-edge)
3. [Mozilla Firefox](/en/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#mozilla-firefox)
4. [Apple Safari](/en/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#apple-safari)

<Aside type="note">

The screenshots below may vary slightly depending on your browser version.

</Aside>

### Google Chrome

<Steps>
<ol>

<li>

In the address bar, click the icon to the left of the URL. Find the _**Notifications**_ row and change the value from _**Block**_ to _**Allow**_.

<Figure src={img0} alt="Chrome site information with the Notifications permission highlighted" width={650} align="left" />

</li>

<li>

Close the settings panel and reload the Braver page for the changes to take effect.

</li>

</ol>
</Steps>

### Microsoft Edge

<Steps>
<ol>

<li>

In the address bar, click the lock icon to the left of the URL. Click _**Permissions for this site**_, then in the _**Notifications**_ section, change the setting from _**Block**_ or _**Ask (default)**_ to _**Allow**_.

<Figure src={img1} alt="Edge site permissions with Notifications set to Allow" width={650} align="left" />

</li>

<li>

Reload the Braver page to apply the changes.

</li>

</ol>
</Steps>

### Mozilla Firefox <a href="#mozilla-firefox" id="mozilla-firefox"></a>

<Steps>
<ol>

<li>

In the address bar, click the shield or lock icon to the left of the URL.&#x20;

<Figure src={img2} alt="Firefox site information panel opened from the shield icon" width={650} align="left" />

</li>

<li>

In the _**Permissions**_ section, find _**Notifications**_ and click the "**X**" next to _**Blocked**_ to remove the block.

<Figure src={img3} alt="Firefox permission popover with blocked notifications ready to clear" width={650} align="left" />

</li>

<li>

Reload the Braver page. You should now see a permission request for notifications.

</li>

</ol>
</Steps>

### Apple Safari

<Aside type="caution">

Safari handles notification permissions differently from other browsers. Web notifications must be enabled in Safari's settings.

</Aside>

<Steps>
<ol>

<li>

In the menu bar, click _**Safari**_**, then&#x20;**_**Settings**_ (or _**Preferences**_ in older versions).

<Figure src={img4} alt="Safari menu with Settings highlighted" width={650} align="left" />

</li>

<li>

Click the _**Websites**_ tab in the settings window. In the left column, click _**Notifications**_. Find **app.braver.net** in the list and change the notification setting from _**Deny**_ to _**Allow**_.

<Figure src={img5} alt="Safari Websites settings with notifications allowed for app.braver.net" width={650} align="left" />

</li>

<li>

If Braver doesn't appear in the list, open the Braver application and you should see a permission request.

</li>

<li>

Close the settings and reload the Braver page.

</li>

</ol>
</Steps>
