<Aside type="note">

Braver sends you new message notifications and weekly summaries by email. If you sign in through one of our integration partners, your email may not be shared with Braver; you can add it manually.&#x20;

</Aside>

<Steps>
<ol>

<li>

### Click your profile avatar.

<Figure src={img0} alt="Braver home screen with the profile avatar highlighted" width={650} align="left" />

</li>

<li>

### Click your name.

<Figure src={img1} alt="Profile menu with Marie Désilet's name highlighted" width={650} align="left" />

</li>

<li>

### Select the _Settings_ tab.

<Figure src={img2} alt="Marie Désilet's profile with the Settings tab highlighted" width={650} align="left" />

</li>

<li>

### Under Communications, click _Email(s)_.

<Figure src={img3} alt="Communications settings with Email(s) highlighted" width={650} align="left" />

</li>

<li>

### Click _Add_.

<Figure src={img4} alt="Empty Email(s) page with the Add button highlighted" width={650} align="left" />

<Aside type="note">

If an email address is already listed, use **Add** to register another address. After verifying it, you can set the new address as your main email.

</Aside>

</li>

<li>

### Enter your email, then click _Add this email_.

<Figure src={img5} alt="Email form with the address field and Add this email button highlighted" width={650} align="left" />

</li>

<li>

### A validation code is sent to your email. Open your inbox and look for an email titled _Braver | Security code for new email address_.

<Figure src={img6} alt="Braver security-code email for verifying a new email address" width={650} align="left" />

</li>

<li>

### Copy the security code from the email.

<Figure src={img7} alt="Verification code highlighted in the Braver email" width={650} align="left" />

</li>

<li>

### Go back to the add email page and paste the code in the field provided.

<Figure src={img8} alt="Email verification page with the six-digit code field highlighted" width={650} align="left" />

</li>

<li>

### Click _Validate_ to finish adding the email.

<Figure src={img9} alt="Email verification page with a complete code and Verify button highlighted" width={650} align="left" />

</li>

<li>

### Click _Set as main_.

<Aside type="note">

Set it as your main email if you want it to replace an older one, or if it is the first email added to your settings!

</Aside>

<Figure src={img10} alt="Verified email page with Set as main highlighted" width={650} align="left" />

</li>

<li>

### Your email now appears with the _Main_ label.

<Figure src={img11} alt="Email(s) list showing the verified address labeled Main" width={650} align="left" />

</li>

</ol>
</Steps>
