## Step by Step

<Aside type="caution">

Currently, once the friend request is accepted, it is impossible to close the direct messaging channel.

This is a limitation that will be corrected soon.

</Aside>

<Steps>
<ol>

<li>

**Go to the Network page.**

<Figure src={img0} alt="" width={375} align="left" />

</li>

<li>

**To accept a friend request, go to Network tab and select this friendship icon in top right.**

<Figure src={img1} alt="" width={375} align="left" />

</li>

<li>

**Select the received invitation.**

<Figure src={img2} alt="" width={362} align="left" />

</li>

<li>

**At this point, you can&#x20;**_**Accept**_**&#x20;or&#x20;**_**Ignore**_**&#x20;the friend request. If you prefer to ignore the request, the person who invited you will not receive a message about it.**

<Figure src={img3} alt="" width={375} align="left" />

</li>

</ol>
</Steps>
