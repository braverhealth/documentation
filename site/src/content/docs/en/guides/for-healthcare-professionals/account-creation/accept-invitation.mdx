## Step by Step

<Steps>
<ol>

<li>

#### In the email you received, click on the button inviting you to accept the invitation.

</li>

<li>

#### One of the following screens might be displayed

*   If this is the first time you are opening Braver, and Braver has never been opened on your device, you will see a screen like the following:

    <Figure src={img0} alt="Choose an account screen with options to use another account or create one" width={563} align="left" />

    \
    You can then choose the "Create a new account" option to continue to [step 3](/en/guides/for-healthcare-professionals/account-creation/accept-invitation#follow-account-creation-steps), unless you have already created a Braver account in the past (in which case you should choose the other option, and you will directly go to [step 4](/en/guides/for-healthcare-professionals/account-creation/accept-invitation#enter-invitation-secret-code-or-answer-secret-question)).
*   If this is the first time you are opening Braver, but Braver has already been used by someone else on your device, you will see a screen like the following:

    <Figure src={img1} alt="Choose an account screen listing existing device users and new-account options" width={563} align="left" />

    \
    You can then choose the "Create a new account" option to continue to [step 3](/en/guides/for-healthcare-professionals/account-creation/accept-invitation#follow-account-creation-steps), unless you have already created a Braver account in the past (in which case you should choose one of the other options, and you will directly go to [step 4](/en/guides/for-healthcare-professionals/account-creation/accept-invitation#enter-invitation-secret-code-or-answer-secret-question)).
*   If you have already created your account in the past with the same email address as the invitation, but your session is not already active on your device, you will see a screen like the following:

    <Figure src={img2} alt="Sign-in screen with Microsoft and password options" width={563} align="left" />

    \
    In this case, you should enter your password and in the next step, the security code you will receive by email or SMS, in order to proceed to [step 4](/en/guides/for-healthcare-professionals/account-creation/accept-invitation#enter-invitation-secret-code-or-answer-secret-question).
*   If you have already created your account in the past with the same email address as the invitation, and your session is already active on your device, you will see a screen like the following:

    <Figure src={img3} alt="Six-box PIN entry screen for an active session" width={563} align="left" />

    \
    In this case, you should simply enter your PIN to proceed to [step 4](/en/guides/for-healthcare-professionals/account-creation/accept-invitation#enter-invitation-secret-code-or-answer-secret-question).

</li>

<li>

#### Follow the account creation steps

<Aside type="note">

This step is only necessary if this is the first time you are using Braver.

</Aside>

You can [follow the tutorial](/en/guides/for-healthcare-professionals/account-creation/independent-account-creation#enter-your-email-address-and-password-of-your-choice-then-select-create-my-account) for this purpose.

</li>

<li>

#### Enter the invitation secret code or answer the secret question

<Aside type="note">

Depending on how the invitation was secured, you will either need to **answer a security question** or **enter a 12-digit secret code** (e.g., 1234-1234-1234).

If it asks for a secret code, you will find it **under the invitation button** in the invitation email you clicked on in [step 1](/en/guides/for-healthcare-professionals/account-creation/accept-invitation#in-the-email-you-received-click-on-the-button-inviting-you-to-accept-the-invitation).

</Aside>

<Figure src={img4} alt="Accept invitation screen with the security-answer field highlighted" width={563} align="left" />

</li>

</ol>
</Steps>
