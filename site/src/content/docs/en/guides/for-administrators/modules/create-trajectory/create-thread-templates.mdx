Thread templates let you quickly create a discussion thread in a care channel. They can include a title, a first message and the participants to include and notify.

Since a thread template is addressed to the trajectory's actors, [configure the actors](/en/guides/for-administrators/modules/create-trajectory/configure-actors) first.

## Create a Thread Template

<Steps>
<ol>

<li>

In the trajectory, select **Thread templates**, then click **Add thread template**.

<Figure src={img10} alt="Thread templates section and Add thread template button" width={563} align="left" />

</li>

<li>

Name the template, then click **Add thread template**.

<Figure src={img11} alt="Thread template name field" width={277} align="left" />

</li>

</ol>
</Steps>

The template is then configured in three tabs: **Information**, **Content** and **Actors to include**.

<Aside type="caution" title="Save each tab">

After changing a tab, click **Save**.

<Figure src={img13} alt="Thread template Save button" width={563} align="left" />

</Aside>

## Information Tab

<Figure src={img12} alt="A thread template's Information tab" width={563} align="left" />

| Marker | Option | Description |
| --- | --- | --- |
| A | Template name | Change the template's name (optional). |
| B | Coming soon | — |

## Content Tab

Add the discussion thread's **title** and its **first message**.

<Figure src={img14} alt="Content tab: thread title and first message" width={563} align="left" />

## Actors to Include Tab

Check the actors to include and notify when this discussion thread is sent.

<Figure src={img16} alt="Actors to include tab" width={563} align="left" />

<Aside type="note">

The other actors can access the thread in the care channel, but aren't notified.

</Aside>
