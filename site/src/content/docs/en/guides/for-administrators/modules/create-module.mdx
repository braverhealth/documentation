To configure different elements (directories, resource identifiers, trajectories and segments) and share them with your organizational units, you must start by creating a module.

<Steps>
<ol>

<li>

### Make sure you are in the right organization and organizational unit, if this applies to you.

<Figure src={img0} alt="Organization and organizational unit selectors highlighted on the Modules page" align="left" />

</li>

<li>

### Go to the _Modules_ page.

<Figure src={img1} alt="Modules item highlighted in the admin console sidebar" align="left" />

</li>

<li>

### Click _Create module_.

<Figure src={img2} alt="Create module button highlighted on the empty Modules page" align="left" />

</li>

<li>

### Click _Create module_.

<Figure src={img3} alt="Create a new module dialog with the Create module button highlighted" width={563} align="left" />

</li>

<li>

### The module is created!

<Figure src={img4} alt="Created module details and organizational unit access list" align="left" />

</li>

</ol>
</Steps>

<Aside type="note">

If you have several organizational units and want to share the same resources with them, you can create a module for each one, then check which organizational units can use them.

<Figure src={img5} alt="First two organizational units selected to access the module resources" />

</Aside>
