### Bulk Provision Users

<Aside type="note">

Once users are imported, they are visible to the members of your organization and can be added to discussion threads. They receive emails and can communicate in "Braver Connect" mode until they choose to create their account.

</Aside>

<Steps>
<ol>

<li>

Click your profile avatar, then select **Admin console**.

<Figure src={img0} alt="Profile menu with Admin console option" width={500} align="left" />

</li>

<li>

In the admin console, click **User Provisioning**.

<Figure src={img1} alt="Users page showing the User Provisioning button" width={750} align="left" />

</li>

<li>

Click **Download Template**.

<Aside type="danger">

Make sure you have completed step 1: create the workplaces and teams in the admin console.

</Aside>

<Aside type="caution">

If you change the teams or workplaces, download the template again and use the new one.

</Aside>

<Figure src={img2} alt="User Provisioning dialog with Download Template highlighted" width={650} align="left" />

</li>

<li>

Fill in the rows of the **User Entries** sheet. Don't change the other sheets marked by the red box at the bottom of the workbook.

<Aside type="note">

For yes/no columns, use the values required by the template you downloaded. This captured example uses TRUE/FALSE; if your template uses Yes/No, follow that format.

</Aside>

<Figure src={img3} alt="User Entries spreadsheet with the other worksheet tabs marked" width={800} align="left" />

</li>

<li>

Optionally select the **SSO Issuer** provided by the Braver team, then click **Upload Spreadsheet**.

<Figure src={img4} alt="User Provisioning dialog with Upload Spreadsheet highlighted" width={650} align="left" />

</li>

<li>

If all status icons are green, click **Provision Users**.

<Figure src={img5} alt="Review Import showing four valid users and the Provision Users button" width={800} align="left" />

<Aside type="note">

If errors are reported, review your spreadsheet and click **Start Over**. You will go back to step 5 of this guide.

<Figure src={img11} alt="Review Import showing one invalid row and the Start Over button" width={800} align="left" />

</Aside>

</li>

<li>

Click **Confirm**.

<Figure src={img6} alt="Confirm Provisioning dialog for four users" width={563} align="left" />

</li>

<li>

A message confirms that the action succeeded. Click **OK**.

<Figure src={img7} alt="Users Provisioned confirmation with OK button" width={500} align="left" />

</li>

<li>

To check account creation status, click **Provisioned Users**. An hourglass means that the user hasn't created a Braver account yet. After they create one, they move to the **Users** tab.

<Aside type="note">

**REMINDER:** Once users are imported, they are visible to the members of your organization and can be added to discussion threads. They receive emails and can communicate in "Braver Connect" mode until they choose to create their account.

</Aside>

<Figure src={img8} alt="Provisioned Users list with four pending hourglass statuses" width={750} align="left" />

</li>

</ol>
</Steps>

### Remove Users from the Imported List

<Steps>
<ol>

<li>

In the admin console, click **Provisioned Users**, then select the trash can on the same row as the user to remove.

<Figure src={img9} alt="Provisioned Users list with the second-row delete action highlighted" width={750} align="left" />

</li>

<li>

Confirm by clicking **Delete**.

<Figure src={img10} alt="Delete Provisioned User confirmation for Antoine Gendron" width={750} align="left" />

</li>

</ol>
</Steps>
