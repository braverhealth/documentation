## The Problem

Wi-Fi power saving mode reduces how often your phone communicates with the Wi-Fi network when the screen is off or the device is idle. This can delay your notifications.

## The Solution

To turn this mode off:

<Steps>
<ol>

<li>

#### Go to Settings, then to the Connections section

<Figure src={img0} alt="Samsung Settings with Connections highlighted" width={375} align="left" />

</li>

<li>

#### Go to the Wi-Fi section

<Figure src={img1} alt="Connections screen with Wi-Fi highlighted" width={375} align="left" />

</li>

<li>

#### Tap the three dots at the top right, then Advanced settings

<Figure src={img2} alt="Wi-Fi screen with the More options menu highlighted" width={375} align="left" />

</li>

<li>

#### Then tap Intelligent Wi-Fi

<Figure src={img3} alt="Wi-Fi menu with Intelligent Wi-Fi highlighted" width={375} align="left" />

</li>

<li>

#### Turn off Wi-Fi power saving mode

<Figure src={img4} alt="Intelligent Wi-Fi with Wi-Fi power saving mode turned off" width={375} align="left" />

</li>

</ol>
</Steps>
