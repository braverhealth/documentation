Une **trajectoire** est un modèle de canal de soins. Une fois configurée, elle vous permet de créer rapidement des canaux de soins pour plusieurs patients, avec le même titre et les mêmes acteurs. Vous pouvez aussi y préparer des modèles de fil de discussion, pour ne pas avoir à recopier souvent le même message.

## En bref

La configuration se fait en quatre étapes. Utilisez la table des matières pour aller directement à celle qui vous intéresse.

| Étape | Ce que vous configurez |
| --- | --- |
| 1. Créer la trajectoire | Le nom de la trajectoire, dans le bon module |
| 2. Ajouter des acteurs | Qui peut participer au canal de soins, et à quelles conditions |
| 3. Ajouter des modèles de fil | Des fils de discussion prêts à envoyer : titre, premier message, personnes notifiées |
| 4. Configurer la suggestion automatique | Quand la trajectoire est suggérée dans la fiche du patient |

## Avant de commencer

Les trajectoires sont créées dans un module. Si votre unité organisationnelle n'a pas encore de module, commencez par en créer un.

<LinkCard title="Créer un module" href="/guides/for-administrators/modules/create-module" />

<Aside type="tip">

Plusieurs configurations sont possibles. N'hésitez pas à demander conseil à la personne qui vous accompagne dans votre déploiement!

</Aside>

## 1. Créer la trajectoire

<Steps>
<ol>

<li>

Vérifiez que vous êtes dans la bonne unité organisationnelle, puis cliquez sur **Modules**.

<Figure src={img0} alt="Sélection de l'unité organisationnelle et menu Modules" width={375} align="left" />

</li>

<li>

Cliquez sur **+**, puis sélectionnez **Trajectoire**.

<Figure src={img1} alt="Bouton + et choix Trajectoire" width={375} align="left" />

</li>

<li>

Donnez un nom à la trajectoire, puis cliquez sur **Créer**.

<Figure src={img2} alt="Champ du nom de la trajectoire et bouton Créer" width={375} align="left" />

</li>

</ol>
</Steps>

## 2. Ajouter des acteurs

Les acteurs déterminent qui peut participer à un canal de soins et à quelles conditions. Un acteur peut être un utilisateur, une équipe, ou les deux.

### Créer un acteur

<Steps>
<ol>

<li>

Sélectionnez **Acteurs**, puis cliquez sur **Ajouter un acteur**.

<Figure src={img3} alt="Section Acteurs et bouton Ajouter un acteur" width={563} align="left" />

</li>

<li>

Donnez un nom à l'acteur, puis cliquez sur **Ajouter un acteur**.

<Figure src={img4} alt="Champ du nom de l'acteur" width={375} align="left" />

</li>

</ol>
</Steps>

L'acteur se configure ensuite dans trois onglets : **Informations**, **Utilisateur** et **Équipe**.

<Aside type="caution" title="Enregistrez chaque onglet">

Après avoir modifié un onglet, cliquez sur **Enregistrer**.

<Figure src={img6} alt="Bouton Enregistrer" width={563} align="left" />

</Aside>

### Onglet Informations

<Figure src={img5} alt="Onglet Informations d'un acteur, options A à E" align="left" />

| Repère | Option | Description |
| --- | --- | --- |
| A | Nom | Le nom de l'acteur. |
| B | Description | S'affiche sous le nom de l'acteur dans le menu de gauche. |
| C | Sélection obligatoire | Activez l'interrupteur pour que l'acteur fasse obligatoirement partie de la trajectoire. |
| D | Nombre maximal | Le nombre maximal de ce type d'acteur dans la trajectoire. Laissez **0** pour un nombre illimité. |
| E | Mode d'assignation | Les membres de l'équipe inclus dans les fils de discussion (voir le tableau ci-dessous). |

**Modes d'assignation**

| Mode | Qui est inclus dans les fils de discussion |
| --- | --- |
| Unique | Toujours un membre de l'équipe, s'il est assigné au canal ou s'il est le seul membre de l'équipe qui participe au canal. |
| Tous | Tous les membres de l'équipe qui participent au canal. |
| Aucun | Aucun membre de l'équipe. Les fils de discussion arrivent dans la boîte de triage de l'équipe. |

### Onglet Utilisateur

Utilisez cet onglet pour que l'acteur soit choisi parmi des utilisateurs précis.

<Figure src={img7} alt="Onglet Utilisateur d'un acteur, options A à C" width={563} align="left" />

| Repère | Option | Description |
| --- | --- | --- |
| A | Sélection d'utilisateurs | Activez l'interrupteur pour choisir des utilisateurs (plutôt qu'une équipe, par exemple). |
| B | À venir | — |
| C | Utilisateurs proposés | Les utilisateurs qui apparaîtront dans la trajectoire. Lors de l'activation du canal de soins, on pourra en choisir un ou plusieurs dans un menu déroulant. |

### Onglet Équipe

Utilisez cet onglet pour que l'acteur soit une équipe.

<Figure src={img9} alt="Onglet Équipe d'un acteur, options A à D" width={563} align="left" />

| Repère | Option | Description |
| --- | --- | --- |
| A | Sélection d'équipes | Activez l'interrupteur pour choisir des équipes (plutôt qu'un utilisateur, par exemple). |
| B | Modèle d'équipe | Choisissez une équipe parmi [vos modèles d'équipes](/guides/for-administrators/teams/create-team-template-coming-soon). |
| C | Équipe de l'unité organisationnelle | Choisissez une équipe de votre unité organisationnelle. |
| D | À venir | — |

## 3. Ajouter des modèles de fil

Les modèles de fil permettent de créer rapidement un fil de discussion dans un canal de soins. Ils peuvent comprendre un titre, un premier message et les participants à inclure et à notifier.

### Créer un modèle de fil

<Steps>
<ol>

<li>

Sélectionnez **Modèles de fil**, puis cliquez sur **Ajouter un modèle de fil**.

<Figure src={img10} alt="Section Modèles de fil et bouton Ajouter un modèle de fil" width={563} align="left" />

</li>

<li>

Donnez un nom au modèle, puis cliquez sur **Ajouter un modèle de fil**.

<Figure src={img11} alt="Champ du nom du modèle de fil" width={277} align="left" />

</li>

</ol>
</Steps>

Le modèle se configure ensuite dans trois onglets : **Informations**, **Contenu** et **Acteurs à inclure**.

<Aside type="caution" title="Enregistrez chaque onglet">

Après avoir modifié un onglet, cliquez sur **Enregistrer**.

<Figure src={img13} alt="Bouton Enregistrer du modèle de fil" width={563} align="left" />

</Aside>

### Onglet Informations

<Figure src={img12} alt="Onglet Informations d'un modèle de fil" width={563} align="left" />

| Repère | Option | Description |
| --- | --- | --- |
| A | Nom du modèle | Modifiez le nom du modèle (facultatif). |
| B | À venir | — |

### Onglet Contenu

Ajoutez le **titre** du fil de discussion et son **premier message**.

<Figure src={img14} alt="Onglet Contenu : titre et premier message du fil" width={563} align="left" />

### Onglet Acteurs à inclure

Cochez les acteurs à inclure et à notifier lors de l'envoi de ce fil de discussion.

<Figure src={img16} alt="Onglet Acteurs à inclure" width={563} align="left" />

<Aside type="note">

Les autres acteurs ont accès au fil dans le canal de soins, mais ne sont pas notifiés.

</Aside>

## 4. Configurer la suggestion automatique

La suggestion automatique détermine quand la trajectoire est suggérée dans les fiches patients, selon le statut du patient et une plage de dates. Vous sauvez ainsi des clics lors de l'activation, et vos équipes deviennent autonomes si elles ont la responsabilité de configurer un canal de soins pour les patients.

<Steps>
<ol>

<li>

Sélectionnez **Modules**, puis l'onglet **Trajectoires**, et choisissez la trajectoire.

<Figure src={img19} alt="Onglet Trajectoires de la page Modules" />

</li>

<li>

Sélectionnez l'onglet **Suggestion automatique**, puis activez les options voulues.

<Figure src={img18} alt="Onglet Suggestion automatique, options A à D" width={563} align="left" />

</li>

</ol>
</Steps>

| Repère | Option | Effet |
| --- | --- | --- |
| A | Quand le patient est actif | La trajectoire est suggérée pour tous les patients actifs. |
| B | Quand absent du patient | La trajectoire est suggérée automatiquement, sauf aux patients dont le canal de soins correspondant existe déjà. |
| C | Avant la date | La date jusqu'à laquelle la trajectoire est suggérée dans la fiche du patient. |
| D | À partir de la date | La date à partir de laquelle la trajectoire est suggérée dans la fiche du patient. |

<Aside type="tip">

Vous pouvez activer plusieurs options à la fois.

</Aside>
