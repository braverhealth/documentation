<Aside type="note">

Une trajectoire est un modèle de canal de soins. Lorsque vous configurez une trajectoire, vous pouvez ensuite rapidement créer des canaux de soins pour plusieurs patients, selon le même modèle. Le titre du canal de soins sera déjà défini, de même que les acteurs que vous souhaitez voir participer au canal de soins.\
\
C'est également à cet endroit que vous pouvez prévoir un modèle de fil de discussion, ce qui peut vous être utile si vous avez à recopier fréquemment un même message dans le contexte de votre canal de soins.\
\
Plusieurs configurations sont possibles; n'hésitez pas à demander conseil à la personne qui vous accompagne dans votre déploiement!

</Aside>

1. [Créer la trajectoire](/guides/for-administrators/modules/create-trajectory#id-1.-creer-la-trajectoire)
2. [Ajouter des acteurs](/guides/for-administrators/modules/create-trajectory#id-2.-ajouter-des-acteurs)
3. [Ajouter des modèles de fil](/guides/for-administrators/modules/create-trajectory#id-3.-ajouter-des-modeles-de-fil)
4. [Modifier la suggestion automatique](/guides/for-administrators/modules/create-trajectory#id-4.-modifier-la-suggestion-automatique)

<Steps>

### 2. Ajouter des acteurs

<Aside type="note">

Les acteurs déterminent qui peut participer à un canal de soins et sous quelles conditions. Ils peuvent être un utilisateur individuel, une équipe, ou les deux.

</Aside>

<Steps>
<ol>

<li>

**1) Sélectionnez&#x20;**_**Acteurs**_**, puis 2) cliquez sur&#x20;**_**Ajouter un acteur**_**.**

<Figure src={img3} alt="" width={563} align="left" />

</li>

<li>

**1) Donnez un nom à votre nouvel acteur et 2) cliquez sur&#x20;**_**Ajouter un acteur**_**.**

<Figure src={img4} alt="" width={375} align="left" />

</li>

</ol>
</Steps>

#### 2.1 Modifier les informations d'un acteur

<Steps>
<ol>

<li>

**1) Sélectionnez l'onglet&#x20;**_**Informations**_**. Voici les options qui s'offrent à vous:**

A. Modifier le nom de l'acteur;

B. Ajouter une description de l'acteur. Cette description apparaîtra sous le nom de l'acteur dans le menu de gauche;

C. Forcer la sélection de cet acteur en activant l'interrupteur. À ce moment, l'acteur devra obligatoirement faire partie de la trajectoire;

D. Indiquer un nombre maximal de ce type d'acteur dans la trajectoire. Laissez à 0 pour un nombre illimité;

E. Décider si le mode d'assignation est:

* Unique: Toujours inclure un membre de l'équipe s'il est assigné au canal ou s'il est le seul membre de l'équipe participant au canal;
* Tous: Tous les membres de l'équipe participant au canal seront inclus dans les fils de discussion;
* Aucun: Aucun membre de l’équipe qui participe au canal ne sera inclus dans les fils de discussion; ceux-ci arriveront dans la boîte de triage de l’équipe.

<Figure src={img5} alt="" align="left" />

</li>

<li>

**Enregistrez votre progression.**

<Figure src={img6} alt="" width={563} align="left" />

</li>

</ol>
</Steps>

#### 2.2 Modifier le type _Utilisateur_

<Steps>
<ol>

<li>

**1) Sélectionnez l'onglet&#x20;**_**Utilisateur**_**. Voici les options qui s'offrent à vous:**

A. Activer l'interrupteur afin de choisir la sélection d'utilisateurs (en opposition à sélectionner une équipe par exemple);

B. À venir;

C. Indiquer ici le nom des utilisateurs que l'on souhaite voir apparaître dans la trajectoire. Il sera possible de choisir un ou plusieurs de ces utilisateurs dans un menu déroulant lors de l'activation du canal de soins associé.

<Figure src={img7} alt="" width={563} align="left" />

</li>

<li>

**Enregistrez votre progression.**

<Figure src={img8} alt="" width={563} align="left" />

</li>

</ol>
</Steps>

<Steps>
<ol>

**1) Sélectionnez l'onglet&#x20;**_**Équipe**_**. Voici les options qui s'offrent à vous:**

A. Activer l'interrupteur afin de choisir la sélection d'équipes (en opposition à sélectionner un utilisateur par exemple);

B. Choisir une équipe provenant de [vos modèles d'équipes](/guides/for-administrators/teams/create-team-template-coming-soon);

### 3. Ajouter des modèles de fil

<Aside type="note">

Les modèles de fil permettent de créer rapidement un fil de discussion dans un canal de soins. Ils peuvent comprendre un titre, un message de départ et les participants à notifier et à inclure.

</Aside>

<Steps>
<ol>

<li>

**1) Sélectionnez&#x20;**_**Modèles de fil**_**, puis 2) cliquez sur&#x20;**_**Ajouter un modèle de fil**_**.**

<Figure src={img10} alt="" width={563} align="left" />

</li>

<li>

**1) Donnez un nom à votre modèle de fil et 2) cliquez sur&#x20;**_**Ajouter un modèle de fil**_**.**

<Figure src={img11} alt="" width={277} align="left" />

</li>

<li>

**1) Sélectionnez l'onglet&#x20;**_**Informations**_**. Voici les options qui s'offrent à vous:**

A. Modifier le nom du modèle (facultatif);

B. À venir.

<Figure src={img12} alt="" width={563} align="left" />

</li>

<li>

**Enregistrez votre progression.**

<Figure src={img13} alt="" width={563} align="left" />

</li>

<li>

**1) Sélectionnez l'onglet&#x20;**_**Contenu**_**. 2) Ajoutez le titre du fil de discussion ainsi que 3) le premier message de ce fil.**

<Figure src={img14} alt="" width={563} align="left" />

</li>

<li>

**Enregistrez votre progression.**

<Figure src={img15} alt="" width={563} align="left" />

</li>

<li>

**1) Sélectionnez l'onglet&#x20;**_**Acteurs à inclure**_**. 2) Cochez les acteurs qui devront être inclus et notifiés lors de l'envoi de ce fil de discussion.**

<Aside type="note">

Les autres acteurs y auront accès dans le canal de soins, mais ne seront pas notifiés.

</Aside>

<Figure src={img16} alt="" width={563} align="left" />

</li>

<li>

**Enregistrez votre progression.**

<Figure src={img17} alt="" width={563} align="left" />

</ol>
</Steps>

### 4. Modifier la suggestion automatique

<Aside type="note">

C'est ici que vous pouvez configurer quand une trajectoire sera automatiquement suggérée dans les fiches patients. Vous pouvez restreindre les suggestions selon le statut du patient et définir une plage de dates.\
\
Vous pouvez ainsi sauver des clics lors de l'activation en plus de rendre vos équipes autonomes si elles ont la responsabilité de configurer un canal de soins pour les patients.

<img src="../../.gitbook/assets/CleanShot 2026-07-14 at 15.01.31.png" alt="" data-size="original" />

</Aside>

<Steps>
<ol>

<li>

**Sélectionnez 1)&#x20;**_**Modules**_**, puis 2) l'onglet&#x20;**_**Trajectoires**_**. Choisissez ensuite 3) la trajectoire désirée.**

<Figure src={img19} alt="" />

</li>

<li>

**1) Sélectionnez l'onglet&#x20;**_**Suggestion automatique**_**. Voici les options qui s'offrent à vous:**

<Aside type="note">

Il est possible d'activer plus d'une option.

</Aside>

A) _Quand le patient est actif:_ Cette trajectoire sera suggérée pour tous les patients actifs;

B) _Quand absent du patient:_ Cette trajectoire sera suggérée automatiquement, en excluant ceux dont le canal de soins correspondant existe déjà;

C) _Avant la date:_ Indiquez jusqu'à quand vous souhaitez que la suggestion automatique soit suggérée dans la fiche du patient;

D) _À partir de la date:_ Indiquez à partir de quand la trajectoire doit être suggérée dans la fiche du patient.

<Figure src={img18} alt="" width={563} align="left" />

</li>

</ol>
</Steps>
