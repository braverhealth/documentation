### Voici les étapes à suivre pour configurer votre organisation dans Braver:

<Steps>
<ol>

<li>

**Définir la structure de votre organisation**

Si vous utilisez Braver de manière autonome, et que vous n'êtes pas certain de la meilleure structure pour votre organisation, laissez-nous vous aider.

Voici un exemple concret de structure d'une organisation de santé:

<img src="../../.gitbook/assets/file.excalidraw (1).svg" alt="Clinique privée de physiothérapie" class="gitbook-drawing" />

</li>

<li>

**Faire une requête de création d'organisation**

1. Partager le nom de votre organisation à l'équipe Braver à l'aide du formulaire suivant
2. Attendre qu'un membre de l'équipe Braver entre en contact avec vous pour la suite

<Embed url="https://braverhealth.typeform.com/to/JrwlUShz">[https://braverhealth.typeform.com/to/JrwlUShz](https://braverhealth.typeform.com/to/JrwlUShz)</Embed>

</li>

<li>

**Accéder à l'application administrative**

<Aside type="caution">

Si vous n'avez pas encore créé votre compte, vous devriez avoir reçu une invitation par courriel. Voici [le tutoriel](/guides/for-healthcare-professionals/account-creation/independent-account-creation) pour vous aider à créer votre compte.

</Aside>

Vous pouvez accéder à l'application administrative via [https://admin.braver.net](https://admin.braver.net/#/login). Utilisez les mêmes informations que celles pour vous connecter à votre compte Braver (courriel + mot de passe)

</li>

<li>

**Créer vos unités organisationnelles**

Voici [comment créer une unité organisationnelle](/guides/for-administrators/organizational-units/how-to-create-organizational-unit).

Si vous n'êtes pas familier avec le concept d'unité organisationnelle, voici [la documentation](/guides/for-administrators/organizational-units).

</li>

<li>

**Créer vos lieux de travail**

Voici [comment créer un lieu de travail](/guides/for-administrators/workplaces/how-to-create-workplace).

Si vous n'êtes pas familier avec le concept de lieu de travail, voici [la documentation](/guides/for-administrators/workplaces).

</li>

<li>

**Créer vos équipes**

Voici [comment créer une équipe](/guides/for-administrators/teams/how-to-create-team).

Si vous n'êtes pas familier avec le concept d'équipe, voici [la documentation](/guides/for-administrators/teams).

</li>

<li>

**Envoyer les invitations aux utilisateurs**

Avant d'envoyer les invitations aux utilisateurs, il est très important de comprendre quels rôles et permissions vous allez leur octroyer. Voici [la documentation](/for-administrators/users/roles-and-permissions) pour vous aider.

Vous êtes maintenant prêt à envoyer les invitations aux utilisateurs. Voici[ comment inviter un utilisateur](/guides/for-administrators/users/how-to-invite-users).

<Aside type="note">

Pour l'invitation des patients et proches aidants, celle-ci se fait par les cliniciens eux-mêmes autorisés à travers l'application clinicien. Voici [un tutoriel](/guides/for-healthcare-professionals/patient-caregiver-communication/invite-patient-or-caregiver-to-join-braver) pour vous guider.

</Aside>

</li>

</ol>
</Steps>

<Aside type="tip" icon="approve-check-circle">

**Félicitations, votre organisation fait maintenant partie du réseau Braver!** 🎉

* [Autres détails techniques ](/guides/for-administrators/configuration-guide#autres-details-techniques)(si pertinent pour vous)

</Aside>
