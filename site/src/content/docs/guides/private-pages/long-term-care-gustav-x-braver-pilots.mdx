## Accéder à la console administrative

Accédez à la console administrative pour configurer des modèles de canal de soins (trajectoire), suivre les créations de compte de vos utilisateurs, octroyer des permissions supplémentaires, consulter le journal d'audits, etc.

### La capsule de formation

<Aside type="note">

C'est à la personne responsable de votre déploiement chez Braver de vous accorder le rôle d'administrateur dans la console administrative. Suite à cela, vous aurez accès à ladite console.&#x20;

</Aside>

## Octroyer la permission Braver dans Gustav

Dans Gustav Configure, octroyez la permission Braver pour chaque profil nécessaire. Suite à l'activation, la bulle de discussion Braver apparaîtra dans Gustav.

<Aside type="note">

Par défaut, les domaines professionnels correspondent aux équipes dans braver. Il est possible que vous ayez demandé des équipes configurées différemment. Dans ce cas, veuillez vous assurer que chaque domaine professionnel est bien dans la bonne équipe [en suivant ce pas-à-pas](/guides/for-healthcare-professionals/teams/view-teams).

</Aside>

## Suivre les créations de compte

À partir de la console administrative, dans la page des utilisateurs, vous pouvez voir quel employé à créé son compte jusqu'à maintenant.&#x20;

<Aside type="note">

Il est possible de voir qui a créé son compte, mais impossible de voir qui ne l'a pas encore fait. Nous n'avons pas accès à ce type d'information pour le moment.

</Aside>
