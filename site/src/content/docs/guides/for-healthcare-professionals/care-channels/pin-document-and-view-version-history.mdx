## Pas-à-pas

Consultez les pas-à-pas afin d'[Épingler un fichier](/guides/for-healthcare-professionals/care-channels/pin-document-and-view-version-history#epingler-un-fichier), de [Mettre à jour le fichier épinglé](/guides/for-healthcare-professionals/care-channels/pin-document-and-view-version-history#mettre-a-jour-le-fichier-epingle) et de [Consulter l'historique des versions](/guides/for-healthcare-professionals/care-channels/pin-document-and-view-version-history#consulter-lhistorique-des-versions).

### Épingler un fichier

<Steps>
<ol>

<li>

**1) Accédez à la page&#x20;**_**Patients**_**&#x20;et 2) sélectionnez le patient qui vous intéresse ou 3) retrouvez-le grâce à la barre de recherche.**

<Figure src={img0} alt="" width={375} align="left" />

</li>

<li>

**Accédez au canal de soins concerné dans lequel se trouve le fichier à épingler en cliquant sur&#x20;**_**Voir plus**_**.**

<Figure src={img1} alt="" width={375} align="left" />

</li>

<li>

**Sélectionnez le fil de discussion dans lequel il y a un un fichier (photos, vidéos, documents) à épingler.**

<Figure src={img2} alt="" width={375} align="left" />

</li>

<li>

**Cliquez sur les 3 petits points (web) ou appuyez longuement sur le fichier (mobile).**

<Figure src={img3} alt="" width={375} align="left" />

</li>

<li>

**Cliquez sur&#x20;**_**Épingler le document**_**.**&#x20;

Une petite punaise rouge apparaîtra près du fichier. Si nous retournons voir les détails du canal de soins (voir étape 2), nous pouvons voir notre fichier épinglé dans le haut du canal de soins.

<Figure src={img4} alt="" width={375} align="left" />

</li>

</ol>
</Steps>

### Mettre à jour le fichier épinglé

<Steps>
<ol>

<li>

**Dans le canal de soins, 1) nous pouvons voir notre fichier épinglé.**

**On peut remplacer cette version du document épinglé avec une nouvelle version plus récente. Pour cela, 2) cliquez sur les 3 petits points (web) ou appuyez longuement sur le fichier (mobile).**

<Figure src={img5} alt="" width={375} align="left" />

</li>

<li>

**Cliquez sur l'option permettant de mettre à jour.**

<Figure src={img6} alt="" width={375} align="left" />

</li>

<li>

**Cela créera un nouveau fil pour notifier les participants qu'une nouvelle version est déposée. Écrivez un message expliquant les changements puis complétez l'envoi.**&#x20;

<Figure src={img7} alt="" width={375} align="left" />

</li>

</ol>
</Steps>

### Consulter l'historique des versions

<Steps>
<ol>

<li>

**Dans le canal de soins, 1) nous voyons maintenant la dernière version du fichier.**

**Pour voir les versions antérieures des documents, 2) cliquez sur les 3 petits points (web) ou appuyez longuement sur le fichier (mobile).**

<Figure src={img8} alt="" width={375} align="left" />

</li>

<li>

**Cliquez sur&#x20;**_**Ouvrir l'historique de fichier**_**.**

<Figure src={img9} alt="" width={375} align="left" />

</li>

<li>

**Vous verrez ainsi toutes les versions du fichier en question.**

<Figure src={img10} alt="" width={375} align="left" />

</li>

</ol>
</Steps>
