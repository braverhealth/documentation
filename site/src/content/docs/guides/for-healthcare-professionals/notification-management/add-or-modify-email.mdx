<Aside type="note">

Braver vous envoie des notifications de nouveaux messages et des récapitulatifs hebdomadaires par courriels. Si vous vous connectez via l'un de nos partenaires d'intégration, il est possible que votre courriel ne soit pas partagé à Braver; vous pouvez l'ajouter manuellement.&#x20;

</Aside>

<Steps>
<ol>

<li>

### Cliquez sur votre avatar de profil.

<Figure src={img0} alt="" width={375} align="left" />

</li>

<li>

### Cliquez sur votre nom.

<Figure src={img1} alt="" width={372} align="left" />

</li>

<li>

### Sélectionnez l'onglet _Paramètres_.

<Figure src={img2} alt="" width={375} align="left" />

</li>

<li>

### Sous le titre Communications, cliquez sur _Courriel(s)_.

<Figure src={img3} alt="" width={375} align="left" />

</li>

<li>

### Cliquez sur _Ajouter_.

<Figure src={img4} alt="" width={375} align="left" />

<Aside type="note">

Si vous souhaitez remplacer un courriel existant par un nouveau, la page ressemblera plutôt à ceci:

<img src="../../.gitbook/assets/CleanShot 2026-03-02 at 16.36.23@2x.png" alt="" data-size="original" />

</Aside>

</li>

<li>

### Inscrivez votre courriel, puis cliquez sur _Ajouter ce courriel_.

<Figure src={img5} alt="" width={375} align="left" />

</li>

<li>

### Un code de validation sera envoyé à votre courriel. Ouvrez votre boîte de réception et recherchez un courriel intitulé _Braver | Code de sécurité pour nouvelle adresse courriel_.

<Figure src={img6} alt="" width={375} align="left" />

</li>

<li>

### Copiez le code de sécurité contenu dans le courriel.

<Figure src={img7} alt="" width={375} align="left" />

</li>

<li>

### Retournez à la page d'ajout de courriel et collez le code dans le champ prévu.

<Figure src={img8} alt="" width={375} align="left" />

</li>

<li>

### Cliquez sur _Valider_ pour finaliser l'ajout du courriel.

<Figure src={img9} alt="" width={375} align="left" />

</li>

<li>

### Cliquez sur _Désigner comme principal_.

<Aside type="note">

Désignez-le comme principal si vous souhaitez modifier un ancien courriel par celui-ci ou s'il s'agit de votre premier courriel ajouté à vos paramètres!

</Aside>

<Figure src={img10} alt="" width={375} align="left" />

</li>

<li>

### Votre courriel apparaît maintenant avec la mention _Principal_.

<Figure src={img11} alt="" width={375} align="left" />

</li>

</ol>
</Steps>
