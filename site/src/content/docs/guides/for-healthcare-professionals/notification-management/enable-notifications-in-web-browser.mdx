Si vous avez précédemment refusé les notifications de Braver dans votre navigateur, vous devrez accéder aux paramètres du site pour réactiver cette permission.

1. [Google Chrome](/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#google-chrome)
2. [Microsoft Edge](/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#microsoft-edge)
3. [Mozilla Firefox](/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#mozilla-firefox)
4. [Apple Safari](/guides/for-healthcare-professionals/notification-management/enable-notifications-in-web-browser#apple-safari)

<Aside type="note">

Les captures d'écran ci-dessous peuvent varier légèrement selon la version de votre navigateur.

</Aside>

### Google Chrome

<Steps>
<ol>

<li>

Dans la barre d'adresse, cliquez sur l'icône à gauche de l'URL. Trouvez la ligne _**Notifications**_ et changez la valeur de _**Bloquer**_ à _**Autoriser**_.

<Figure src={img0} alt="" width={375} align="left" />

</li>

<li>

Fermez le panneau des paramètres et rechargez la page Braver pour que les changements prennent effet.

</li>

</ol>
</Steps>

### Microsoft Edge

<Steps>
<ol>

<li>

Dans la barre d'adresse, cliquez sur l'icône de cadenas à gauche de l'URL. Cliquez sur _**Autorisations pour ce site**_, puis dans la section _**Notifications**_, changez le paramètre de _**Bloquer**_ ou _**Demander (par défaut)**_ à _**Autoriser**_.

<Figure src={img1} alt="" width={375} align="left" />

</li>

<li>

Rechargez la page Braver pour appliquer les modifications.

</li>

</ol>
</Steps>

### Mozilla Firefox <a href="#mozilla-firefox" id="mozilla-firefox"></a>

<Steps>
<ol>

<li>

Dans la barre d'adresse, cliquez sur l'icône de bouclier ou de cadenas à gauche de l'URL.&#x20;

<Figure src={img2} alt="" width={375} align="left" />

</li>

<li>

Dans la section _**Permissions**_, trouvez _**Notifications**_ et cliquez sur le « **X** » à côté de _**Bloqué**_ pour supprimer le blocage.

<Figure src={img3} alt="" width={375} align="left" />

</li>

<li>

Rechargez la page Braver. Vous devriez maintenant voir une demande de permission pour les notifications.

</li>

</ol>
</Steps>

### Apple Safari

<Aside type="caution">

Safari gère les permissions de notification différemment des autres navigateurs. Les notifications Web doivent être activées dans les préférences de Safari.

</Aside>

<Steps>
<ol>

<li>

Dans la barre de menu, cliquez sur _**Safari**_**, puis sur&#x20;**_**Réglages**_ (ou _**Préférences**_ sur les versions plus anciennes).

<Figure src={img4} alt="" width={375} align="left" />

</li>

<li>

Cliquez sur l'onglet _**Sites web**_ dans la fenêtre des préférences. Dans la colonne de gauche, cliquez sur _**Notifications**_. Trouvez **app.braver.net** dans la liste et changez le paramètre des notifications de _**Refuser**_ à _**Autoriser**_.

<Figure src={img5} alt="" width={375} align="left" />

</li>

<li>

Si Braver n'apparaît pas dans la liste, visitez l'application Braver et vous devriez voir une demande de permission.

</li>

<li>

Fermez les préférences et rechargez la page Braver.

</li>

</ol>
</Steps>

### Besoin d'aide supplémentaire? <a href="#besoin-daide-supplementaire" id="besoin-daide-supplementaire"></a>

Si vous rencontrez des difficultés à activer les notifications, n'hésitez pas à [nous contacter](mailto:support@braver.health).
