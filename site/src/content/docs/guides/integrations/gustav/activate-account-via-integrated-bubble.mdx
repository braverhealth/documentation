## Pas-à-pas

<Aside type="note">

PILOTES: Vous avez testé l’application dans l'environnement de _pré-production_? Il faut recommencer le processus lorsque vous passerez en _production_.

</Aside>

<Steps>
<ol>

<li>

**Dans Gustav, cliquez sur la bulle de discussion.**

<Figure src={img0} alt="" width={563} align="left" />

</li>

<li>

**Sélectionnez&#x20;**_**Je n'ai pas encore de compte Braver.**_

<Aside type="note">

Si vous avez utilisé Braver de manière autonome ou dans un logiciel tiers, choisissez l'option _Utiliser un autre compte_ pour lier ce compte existant avec votre nouvelle équipe dans Gustav.

</Aside>

<Figure src={img1} alt="" width={375} align="left" />

</li>

<li>

**On vous demandera de confirmer que vous désirez réellement continuer sans associer de compte Braver existant, car l'action ne sera pas réversible. Cliquez sur&#x20;**_**OK**_**.**

<Figure src={img2} alt="" width={375} align="left" />

</li>

<li>

**1) Faites défiler jusqu'en bas, puis 2) cliquez sur&#x20;**_**Accepter les conditions d'utilisation**_**&#x20;si vous souhaitez continuer.**

<Figure src={img3} alt="" width={375} align="left" />

</li>

<li>

**Vous devrez ensuite configurer un NIP. Cliquez sur&#x20;**_**Configurez**_**.**

<Aside type="note">

Ce NIP vous sera utile entre autres si vous désirez utiliser Braver sur un appareil mobile.

</Aside>

<Figure src={img4} alt="" width={375} align="left" />

</li>

<li>

**Saisissez votre NIP et répétez-le. Ils doivent être identiques.**

<Figure src={img5} alt="" width={375} align="left" />

</li>

<li>

**Vous y êtes ! Votre compte Braver est maintenant activé !**

<Figure src={img6} alt="" width={375} align="left" />

</li>

</ol>
</Steps>
